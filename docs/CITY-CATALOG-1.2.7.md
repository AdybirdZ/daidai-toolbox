# 1.2.7 地区目录

本版内置目录继续作为天气地区选择的离线入口，城市坐标和名称来自工作区中已核查的中国气象局／中国天气网城市资料，并保留 GeoNames／Open-Meteo 在线搜索作为补充。目录只保存城市或地区的名称、中心坐标、时区和行政区字段，不抓取天气数据。

目录覆盖中国大陆各省级行政区的主要地级及县级天气城市，并包含香港、澳门、台湾城市；补充苏州的姑苏区、虎丘区、吴中区、相城区、吴江区、苏州工业园区、常熟市、张家港市、昆山市和太仓市。内置城市按坐标和显示名称去重。香港、澳门等特别行政区及新区、园区保留其正式行政名称，不强行添加“市”。

目录中使用的中国城市资料位于 `references/weather-fighter-global/web/data/cities.json`，其文件声明来源为中国天气网、中国气象局和 Open-Meteo。本应用只提取公开的名称与坐标字段，用于个人非商业天气查询，并继续在地区选择页保留 GeoNames 署名入口。该目录不改变天气 API 的许可边界。
