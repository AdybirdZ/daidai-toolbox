# 2.0.0 · 中文与英语

在“设置 → 全局设置 → 语言”选择跟随系统（默认）、简体中文或 English，立即应用于内置页面、弹窗、提示、图表标签及历史更新记录。不支持的系统语言使用中文；应用语言不改变设备的系统语言。

中英文均使用 Android XML，同一资源键、格式占位符及稳定数据身份保持一致。切换语言时重建当前页面，保留当前栏目、滚动位置、天文时间、地震会话及已保存资料，并保持设置层级；方向、栏目和机构名称改为动态读取，避免残留另一种语言。定位通知随语言刷新。

语言选择纳入完整配置的导入和导出；非法值在写入前拒绝。旧配置未含语言选项时采用默认规则。恢复默认设置也会恢复跟随系统，不删除地点、路线、名单或课程等长期资料。

用户输入、保存的地点名称、城市目录、源站网页、设备名称及第三方数据可能保留原文。语言选择页保留“简体中文”和“English”的各自名称，便于识别。模型、数据许可和权限范围沿用上一版本；本轮没有新增权限、依赖或数据来源。

版本为 2.0.0 / versionCode 43，继续使用原包名和签名，可从 1.3.2 覆盖升级。历史英文内测包 versionCode 为 900，单独保留在本地；它不是此次正式发布资产。

大版本更新的判断依据为底层代码变动或易用性更新，此约定已加入开发者准则。验证范围和未验证项见 [测试记录](../TESTING.md)。
