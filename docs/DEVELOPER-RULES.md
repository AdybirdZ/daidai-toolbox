# 呆呆工具箱开发者准则

本准则依据用户自建项以来的要求整理。每次更新开始、提测前和发布前均须完整阅读，并对本次变更逐项复核。新要求优先于旧要求；已取消的设计只保留在历史更新记录中，不得重新引入。存在不可验证或尚未完成的要求时，如实说明，不以“构建通过”代替功能验收。

## 一、工作区、版本与交付

1. 唯一开发源码及 Git 仓库为 `source/`，历史源码仅供查阅；工作区通用脚本在根目录 `scripts/`，临时材料在 `work/`，交付在 `releases/<版本>/`。
2. 以 manifest、Gradle、Git 状态核实当前版本；保留包名 `org.simpleweather.app` 和原签名，升级不得丢失课程、地区、地点、路线或用户设置。
3. 正式版本默认上传 GitHub 主分支、版本标签及 Release，无须重复征求发布许可。仅用户明确要求本地保存的版本不得上传；`pre2.0.0-1` 英文内测包及独立原型属于本地材料。
4. 用户明确要求覆盖的版本直接覆盖，不制造多份同名交付或额外备份；其他历史正式版本独立保留。备份、签名私钥、凭据、SDK、模拟器和缓存不得进入公开仓库或源码压缩包。
5. 每个版本须更新应用内折叠更新记录、CHANGELOG、当前 README、版本文档及交付索引。重进更新记录时全部收起，保留全部历史版本记录。
6. **“关于”、数据来源入口、数据来源与隐私等当前版本显示读取安装包版本，禁止各自手写版本号。** manifest 与 Gradle 的名称和版本代码须一致；HTTP 客户端标识也须检查。此项专门防止 1.2.8 遗漏更新“关于”版本号的错误再次发生。
7. 发布前核对源码提交、标签、APK 内版本、签名、源码包内容、说明和 SHA-256；上传后再核对远端提交及每项 Release 资产哈希。禁止发布旧 APK 或先宣称完成再补做功能。
8. 使用工作区 `scripts/test.ps1`、`scripts/build.ps1`；除已有测试外，为数据去重、导入、状态恢复等高影响逻辑增加有行为意义的检查，并针对交互进行模拟器或实机验证。未实测硬件功能须明确限制。
9. 本文件纳入公开 GitHub 源码，本地也保留；`AGENTS.md` 明确每次更新先阅读本文件。发布核查结果留在本版本验证文档中。

## 二、文字、语言与界面

1. 用户可能使用简称、口语、错字或不规范专业术语，应理解意图后使用准确、规范且符合中文习惯的文字，不原样粘贴。乱码或明显误输入不进入产品文案。
2. 去除重复数值、重复操作说明、无助于理解的实现细节和无关页面中的内部排版提示。README 只介绍当前行为、使用与构建，不堆叠历次聊天和过时功能；历史内容放更新记录。
3. 说明按对应栏目默认显示顺序组织；所有设置说明放在该设置页面控件下方、内容末尾，字段名称仍紧邻对应输入框。所有可调整排序的页面均明确列出实际默认排序；固定排序方式单选项已有“（默认）”时，不再另段重复默认选项；更改当前排序不得改变默认说明。统一一个自然段间距，中英文与数值单位间留适当空格。
4. 全部内置界面文字（含历史页面、提示、图表标签及更新记录）使用 Android XML 语言资源，键名稳定。`identifiers.xml` 仅保存不可翻译的历史数据标识，不得作为界面文字库；天体等名称通过独立显示资源翻译，不能改变已保存的偏好键。中文正式版不混入未发布的英文资源；本地英文内测版同步翻译本次变化，不能把仅翻译几十个资源的混合界面说成完整英文版。
5. 语言入口使用“内测版”，说明英文内测包暂未上传 GitHub；正式多语言功能在对应版本实装后才更改说明。
6. 页面标题为“呆呆工具箱 · 当前栏目”，下方小字为“呆呆鸟使用 Codex 制作”；应用图标为蓝黄工具箱，正常尺寸且四周留白。
7. 设置按层级组织，返回回到上一级；更改选项留在当前设置页，不自动退出。取消不写入数据。默认选项在无固有顺序的选项中置顶，说明明确且不冗余。
8. 所有按钮、输入框、链接区域四周有留白，按钮之间间距一致；不允许相邻按钮粘连或边框碰字。行内按钮根据数量等分，图标与文字居中，标签不遮挡图形。
9. 普通说明不能长按选字；输入框保留正常编辑能力。弹窗避免低帧率位移动画；数值更新和时间切换不得先跳顶部再恢复，不得出现闪屏。
10. 栏目与底栏支持显示控制和排序；只显示一栏时隐藏底栏，五栏及以上使用两侧按钮翻页，禁止底栏手指横滑。天气地图、天文默认隐藏，保留用户已有排序。
11. 全局设置集中管理背景、描边、分类文字与按钮配色、时间、语言、权限与系统限制、底部栏目、缓存及恢复默认设置；设置主顺序及子设置顺序与页面默认栏目顺序相符，相关开关归入对应子设置。
12. 背景由系统选择器导入，支持拖动、缩放和裁剪使用区域，不保留冗余微调按钮；背景亮度增大表示图片更明亮、明显。描边默认关闭、默认黑色。
13. 界面颜色分六类独立设置：普通按钮（默认蓝色）、链接按钮（默认黑色）、正文（默认黑色）、标题（默认黑色）、选择项（默认黑色）、说明文字（默认灰色）。普通按钮不包括链接；深色按钮固定白字，浅色背景与按钮颜色配套。各类支持七种彩色、黑色及十六进制自定义，说明文字另有灰色。开关滑钮、单选圆点和复选勾选固定蓝色，不受用户配色影响；选择项颜色仅控制文字。输入内容归正文，输入提示和普通图表注释归说明；警告、指南针北向、天体和卫星系统等辨识色不随分类文字配色更改。课程七种预设用中文颜色名称，自定义显示十六进制；兼容旧索引与配置，异常颜色回退蓝色，不得崩溃。输入框须有稳定的左右内边距。
14. 全局时间设置用于各页相关时刻，显示明确时区；每日天气、日出日落等必须保持其日历语义。经纬度统一经度在前、纬度在后，W/E、S/N 和正负号含义准确。

15. 同类设置必须合并至对应分组，避免在上一级堆叠按钮。例如，卫星系统显示、明细排序、天空图旋转和接收行为归入“卫星”；传感器显隐排序和环境光来源归入“传感器”。分组入口页尽量仅保留控件；必要的行为、权限、测量局限与默认说明放在相应具体设置内，网络定位间隔说明也置于选项后。保留说明文字或因客观限制未遵守任一准则时，必须在交付中说明具体内容和原因，不得静默略过；已有用户明确要求保留的说明优先。

## 三、地区与天气

1. 中国城市目录包含大陆全部现行直辖市、地级市和县级市，以及香港、澳门、台湾全部现行市；保留苏州市下辖行政区。不要把自治州、地区、盟当成城市，不得机械添加“市”。
2. 用户名单与现行行政区划不一致时核查官方资料；撤市设区、合并、旧名称作为检索别名或对应现行区保留，不能生成两个相同结果。新增城市也要补齐，不能只照抄旧名单。
3. 必须联网核对名称、行政层级和所属区域，并结合 GeoNames 等有明确使用依据的数据确认坐标。记录来源、数据日期、GeoNames ID、匹配依据和缺失项；不可凭拼音、同音、名称相似或随意坐标填充。
4. 以稳定行政身份、所属省份、来源标识和经核实的别名统一目录、搜索、收藏与当前地区。严禁跨省同名城市误合并，也严禁市与县、区、镇误合并；仅坐标接近不足以证明同一地点。
5. 禁止用自治州中心、辖区平均值替代下属城市。城市天气查询使用该城市经核实的代表地点，明确它不代表整个行政范围处处相同。
6. 地区选择仅保留“我的地区”和搜索，不重新加入常用城市或预置城市长列表；搜索按钮在输入框外，地区名称不重复触发地区选择器。搜索结果和收藏条目显示经度、纬度及 E/W、N/S；坐标精细显示不等于测量精度。
7. 天气为 Open-Meteo 模型结果，明确非台站实时观测；摄氏度用 ℃，降水概率不得写成降水量。紫外线风险说明不重复上方数值。
8. 天气图例按现有经核实的 WMO 命名和支持代码维护，解释服务仅返回部分代码、地区限制和未知天气触发条件，保留官方来源链接；不把服务简化描述无条件当成 WMO 逐字定义。
9. 天气图标雨、雪、冰雹等按类型及强度绘制；除闪电外云下要素使用深蓝。夜间月牙使用真实路径，不以异色圆掩盖；晴天独立图标居中、大小合理，多云月牙充分露出。
10. 刷新成功给出可读提示，遵守缓存和请求限流。天气地图独立栏目，保留切换图种入口，官方网页可双指缩放；“在浏览器中打开”采用无背景、带外链箭头的链接形式，点击区域及周围间距充足。

## 四、天文

1. 星空正方形、坐标与投影定义准确。标签优先固定在星点上方；冲突时较低星点改放下方，再冲突隐藏标签而保留星点可选，避免标签远离本体。
2. 恒星、行星（含天王星、海王星）、太阳、月球和较亮深空天体可选，显示方位角、高度角及适用的视星等。太阳不显示视星等；月球估算说明方法和限制。
3. 北斗七星、参宿一至参宿七齐全；织女一、河鼓二、勾陈一用规范名称。梅西耶表内深空天体使用“M编号 天体名称”。
4. 亮星及行星、深空天体支持手动显隐或按星等上限筛选，步进 0.1。深空天体注明总视星等不等于肉眼可见程度。
5. 选择用缓慢旋转的断开十字表示；改变时间保留选中，地平线下不绘制选择十字。对准天空用红色实体十字，与选择效果区分；按实际 XYZ 姿态计算外置相机方向或手机上沿方向，默认外置相机，不用固定加 90° 伪造方向。星图保持固定，红十字按真实高度角和真北方位角在天球上移动，大小接近选择十字；仅在地平与无网格模式工作，地平线下隐藏。设备方向说明置于星图下方，同类内容同段。
6. 时间控制集中成框；第一行 −15 分钟、当前、+15 分钟，支持 −1 天、+1 天和年月日时分数字输入，不使用钟盘。按钮更新不跳页、不闪屏。
7. 月相、照亮比例、近似月龄、距下次满月独立为月球信息；“月亮”统一“月球”。曙光、暮光按早晚区分，不使用不准确的“仍”字。
8. 流星雨显示为参考极大日前后 3 天的辐射点，不能称为实际完整活跃期；天体、算法、星等均注明近似性质和可核验来源。

## 五、状态、定位、传感器、地点与路线

1. 默认真北，明确磁偏角估算来源；俯仰、横滚大字显示，上沿抬起为正、左滚负、右滚正。水平/垂直定位误差半径大字显示，垂直误差在海拔下方；WGS84 椭球高不等同海平面正高。
2. 卫星名称用国家/地区加英文缩写，系统默认顺序北斗、美国、欧洲、俄罗斯、日本、印度、其他；明细可按系统或载噪密度比排序。说明按同一顺序写。
3. 卫星图固定方向为上北下南左西右东，可跟随设备旋转且默认开启；选中使用缓慢旋转的十字。更新不得让展开的明细滚回顶部。
4. 开始卫星接收同时开启当前位置更新，避免路线误判定位未开启；停止定位同时停止卫星接收。卫星接收默认离开页面暂停、返回继续，可设置返回后不自动继续。定位持续运行默认关闭，主动开启使用前台服务和可停止通知。
5. 网络定位间隔明确为系统请求最短间隔，默认 5 秒；最近定位时间实时变化，不将重复坐标误称为新定位。网络方式依赖系统服务及网络，不能笼统称定位无需联网。
6. 地点无应用层数量上限，可排序、改名、修改颜色和显隐；编辑保留位置。地点图同时显示多个点，以选中目标确定比例，超界点缩小显示在外圈。
7. 保存地点表单坐标不随定位自动变化；点击“重新定位”才更新输入框。定位年龄实时变化，说明先交代按钮行为。路线与地点支持本机 JSON 导入导出。
8. 传感器说明按默认栏目顺序：陀螺仪、含重力加速度、线性加速度、重力、磁场、气压、环境光、距离、环境温度、相对湿度。先写总说明及缺失规则，再写各项含义；环境温度与下方电池栏目中的电池温度区分。
9. 除位置结果外状态显示目标刷新间隔 50 毫秒，实际采样依硬件；不再提供传感器帧率设置。电池电流默认系统符号，可反转；不同厂商定义不同。电池健康状态是系统报告，不是剩余容量测量或安全保证。电流和电荷读取单位分别设置，默认采用 Android 标准微安、微安时；只在用户明确选择毫安、毫安时后变更换算，不按品牌或数值大小推断。保留原始值供核对，缺失／错误接口不得伪装为有效读数；单位设置纳入配置校验与转移。
10. 环境光可选系统传感器或前/后置相机；相机为相对亮度样本，不伪称照度。无需预览窗口和初始启动按钮；相机读数下提供暂停/恢复切换按钮，暂停必须关闭会话、设备及图像读取器，返回栏目或重建视图不得自行解除暂停；后台等情况持续使用相机默认关闭，并遵守系统权限与生命周期规则。室内参数默认曝光时间 200 ms、感光度 ISO 1000，室外默认 5 ms、ISO 50，两组均可设置且同时显示读数；按图像时戳匹配各自曝光结果，禁止把上一帧、另一组参数或自动曝光读数冒充对应测量。旧版参数保留为室内参数，完整配置导入导出包含两组参数；输入范围与设备实际范围分开说明，实际采用值必须如实展示。优先固定曝光时间及感光度，不支持时尝试锁定自动曝光，拒绝或不支持时如实提示，不能保证任意设备都可固定曝光；不支持时只展示明确标注的自动曝光参考，不伪造两组结果。应用权限、系统定位开关及电池优化入口统一放在“全局设置 → 权限与系统限制”，不放在电池监测设置或状态说明中。电池优化属于系统运行限制，由用户在系统中选择，不自动申请豁免，也不保证后台保活。
11. 传感器、电池、设备字段及状态栏目支持显隐排序；相关设置按页面默认顺序组织，路线位于地点之后、传感器之前，默认排序说明只写在相应排序设置页面，不在产品正文中重复内部排版指令。
12. 路线仅在持续定位开启后绘制；间隔 2～60 秒、默认 5 秒，网络方式不短于网络定位间隔。每个有效位置一个点，直线连接；失败暂停、恢复继续，不伪造插值点。
13. 记录开始/结束合并为切换按钮，结束后停止记录提示；命名保存或删除，不擅自自动保存。删除必须确认，名称输入框保留左右空隙。
14. 路线框持续允许单指平移，拦截父页面滚动；使用滑块缩放，禁用双指缩放。缩放以画框中心为基准，边长 30 米至 10 千米，边缘刻度随比例变化。
15. 保存路线可改名排序。加载时展示全路线；逐点回放只显示当前及此前点和连线，1～20 点/秒，暂停后可上一点、下一点、首点、末点。末帧重新播放不改变缩放。
16. “跟随当前位置/解除跟随当前位置”切换；记录跟随设备位置，回放跟随橙色记录点且持续更新。平移可解除跟随。
17. 每个路线点可选并显示序号、经纬度和时刻；邻近/重叠点先选列表，详情“返回”回到原选择列表。路线删除、保存、播放切换均保持正确状态。
18. 平板旋转、窗口重测量、Activity 重建必须保存栏目、天文时间、地震已获取状态及滚动位置；请求竖屏不足以替代状态恢复。

## 六、地震、授权与隐私

1. 地震是近期目录浏览，不作预警，不接入 `cenc_eew`。中国及周边中大地震覆盖与时效不能无依据保证；展示数据更新状态和各来源局限。
2. 全球目录使用已核实许可的来源，保留署名；技术可访问、CORS、开源客户端或非商业使用不等于上游再发布授权。Wolfx 国内目录仅 `cenc_eqlist`，默认关闭，启用前说明授权未完全确认并点击确认，无强制等待。
3. 数据来源与隐私清楚说明 Wolfx/CENC 适用依据和未确认边界，收到权利人要求立即配合停用和下架，不宣称“绝对合法”或用免责声明代替许可。
4. 主要参数优先中国地震台网已复核，其次其他已复核，最后自动或未知，同级取新；列表显示具体贡献机构中文名，详情保留聚合平台、转发链及原始参数。
5. 简化复核显示为“已复核”“自动结果”“状态未知”，说明机器自动解算和人工处理含义。来源未报告深度固定与否不占一行。
6. 只保留 MMI，不做未经验证的中国烈度换算；列表写“估算震中烈度”，方法括注放详情，未达阈值写“未达阈值，不估算震中烈度”。来源确认或模型烈度与本机估算区分。
7. 最低震级滑块步进 0.1，默认 1，范围含 0 与 ≥7。附近范围只在参考位置附近显示输入，允许 50～5000 km 整数。
8. 距离参考选择定位或手动，默认定位；手动时出现经纬度输入。参考改变自动更新距离；定位参考显示“刷新定位”，不要求先进入状态页面。
9. 发生时刻用完整年份，接口最早一条跨年正确；时间显示 UTC 偏移。列表来源简洁，免责声明、协议和时间解释合并至关于中的数据来源与隐私，文字在按钮前，段距一致。
10. 术语介绍保留震级、MMI、地震类型及复核状态，按最新要求移除主震前震余震和中国烈度。筛选刷新仅保留刷新目录、刷新定位；时间范围用“最近 1 天”，排序明确动作。
11. 新增数据、算法、依赖先核对许可与署名并更新 NOTICE、DATA-LICENSE；官方天气图保留完整原页面，不抓取转发图片。
12. 应用不上传定位、路线、课程或传感器数据，无账号、广告、统计 SDK；网络服务和系统定位的服务方可接收的信息应说明。缓存管理显示空间占用，清理不删除用户长期资料。

## 七、配置导入导出及未来模块

1. 一键导出所有配置应覆盖实际存储的设置、课程、地区、地点、路线和随机选择资料，正确包含背景；不能用不存在的偏好文件名导出空数据。导入完全校验后再确认写入，错误文件不得损坏原数据。
2. 导入不自动启动定位、录制或相机，不恢复接口限流、权限授权、Wolfx 阅读确认等本机运行状态；来源开关遵守启用确认。停止活动采样并重新加载页面模型，类型和范围错误不导致崩溃。
3. 个人导出文件含精确坐标，应在界面说明；只写用户通过系统选择器选定的文件，不上传。未知版本、超大或恶意嵌套文件拒绝，部分失败可回滚。
4. 音乐、设备消息（含手机间蓝牙/局域网）、离线计算器原型保持可合并的独立模块，未获明确合并指令不并入本应用、不上传 GitHub；英语按正式版本计划实装。

## 随机选择

1. 候选内容首尾去空白、规范化并去重，每轮不重复；连续抽取可排除此前抽中项。数量不足须明确提示，不静默补齐、缩小数量或重置。修改候选内容后下次抽取重新建池，载入名单和主动重置会清空进度。
2. 正式抽样使用系统 SecureRandom 默认熵源及无偏部分洗牌，不以当前时间或动画帧作为人为种子。动画仅展示已确定的结果，不用转盘，不闪烁背景或整页；可关闭、跳过，尊重系统动画关闭设置。
3. 草稿、结果、名单和已抽进度本机保存并纳入全配置转移。兼容缺少此分组的旧文件，保留已有随机选择资料；导入后旧页面的生命周期回调不得覆盖新资料。缓存清理及恢复默认设置不删除名单与进度。
4. 名单支持载入、改名和确认删除；当前候选池可以查看尚未抽取内容；保存名单与已保存名单并列，剩余内容位于原保存名单位置；新增栏目保留既有栏目 ID 与顺序。正式中文与本地英文 XML 同步维护。
5. “禁止系统休眠”仅作用于前台窗口；完全退出应用后再次进入时，相机环境光采集保持暂停，需在状态页面恢复。

## 八、既有默认值与细节核对表

下列是用户最终确定的要求；不是让每版重置已有用户选择。后续明确改动时同步更新本准则。

- 学期总周数默认 17 周；上课时间默认苏州大学课程时间。第一至十二节分别为 08:00–08:45、08:50–09:35、09:55–10:40、10:45–11:30、11:35–12:20、14:00–14:45、14:50–15:35、15:55–16:40、16:45–17:30、18:30–19:15、19:25–20:10、20:20–21:05。时间仅数字输入，不用钟盘。
- 课程授课周设置支持全周、单周、双周及自定义周集合，例如 1、3、4、6 周。课程包含名称、地点、教师；默认前缀分别为“课程名称：”“地点：”“教师：”。地点另可用 @ 或无前缀；保存编辑保留顺序，选周直接输入数值。设置名称为“学期设置”“教师前缀”，默认选项置前。
- 描边默认关闭、颜色默认黑色；描边颜色按钮不附“当前 X 色”，不用深灰预设。背景亮度默认为 20，无背景时不显示“无背景图片（默认）”冗余语句。颜色预设与自定义以最新配色要求为准。
- 底部栏目按天气、课程表、状态、天气地图、天文、地震、随机选择的默认序列维护；天气地图和天文默认隐藏，地震及随机选择自加入后默认显示。状态内路线位于地点后、传感器前，具体默认顺序写在排序设置底部，不写到无关产品正文。默认值说明不得给每个条目机械追加“默认”。
- 天气当前卡片的来源按钮放在整个卡片右下，位于地区当地时间下方；图标尺寸足够、文字不贴边。24 小时栏文字和图标全部居中；夜间月牙真实透明，未来 7 天用“降水概率”。天气不保留极光入口。
- 天气地图图种包括日降水量、雷达、气温、卫星云图、天气图；图种切换界面始终可见。雷达只保留一个入口，默认全国，可设置区域，不提供“中国天气网”雷达预设。卫星与天气图使用中央气象台指定原页。“页面可双指缩放”“在浏览器中打开”用规范名称。
