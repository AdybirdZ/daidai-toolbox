# 历史内测版音乐同机迁移（pre-3.0.0-2 / -3）

> 本文仅记录 pre-3.0.0-2 和 pre-3.0.0-3 内测版曾提供的迁移功能。正式 3.0.0 已取消专用迁移入口及对应 ZIP 导入导出，不适用以下步骤。历史辅助 APK 和发布记录保留，不表示正式版支持此流程。

正式 3.0.0 的当前内部音乐仍可使用宿主统一完整备份、恢复及单应用资料导入导出；这与从旧独立音乐迁入数据是不同功能。当前资料管理说明见 [MODULE-HOST.md](MODULE-HOST.md)。

以下历史方案仅用于同一设备，不提供将音频打包换机的功能，不复制原歌曲。

1. 保留旧呆呆音乐及其歌曲文件夹，安装 `DaidaiMusic-0.7.1-migration.apk` 覆盖旧音乐。此辅助包沿用原包名、签名，新增导出入口，是独立 APK 停更前的一次迁移例外。
2. 在旧音乐中打开“设置 → 音乐资料迁移 → 导出音乐资料”，保存生成的 ZIP。
3. 安装对应的 pre-3.0.0-2 或 pre-3.0.0-3 内测宿主，在应用商店安装与其接口兼容的音乐包。打开内部音乐的“设置 → 音乐资料迁移 → 导入音乐资料”，选择 ZIP，并通过系统选择器重新授权原歌曲文件夹。
4. 检查待导入数量并确认覆盖。确认歌单、歌词、曲绘、资料和播放正常后，再自行卸载旧音乐。迁移不删除旧资料和原音频。

转移内容：曲库、播放列表顺序、自定义歌单、我喜欢、评分、备注、标签、BPM、作曲/编曲/演唱者、歌词、私有曲绘与设置。系统权限、目录授权、当前播放位置、运行中定时器不迁移；不会自动播放。

迁移通过原文件身份或目录内唯一相对路径重新关联，并校验文件长度及 SHA-256，不以歌名区分歌曲。不同文件可以同名。缺少或改变的音频会阻止导入，不悄悄改为另一首歌；取消和校验失败不会覆盖当前资料。音频较多时计算校验值可能需要时间，处理期间保留辅助进度说明。

ZIP 不包含音频，仅保存资料及所需歌词、曲绘；单个附属文件上限 16 MiB，总包上限 256 MiB。导出文件包含文件名、路径与个人资料，请自行保管。文件夹授权不能跨包自动继承，重新授权是必要步骤，不表示文件已经复制。
