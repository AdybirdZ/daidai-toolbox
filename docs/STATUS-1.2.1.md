# 状态页 · 1.2.1

本版将状态页的传感器和设备卫星信息做了细化。传感器监听仍使用 Android `SensorManager`，帧率选项只改变系统注册请求，实际采样率受传感器硬件、系统调度和省电策略限制；默认使用 `SENSOR_DELAY_FASTEST`，不承诺固定帧率。

指南针姿态显示定义为：屏幕上方向天空为正俯仰，向左为负横滚、向右为正横滚。当前位置磁偏角使用 Android `GeomagneticField` 的本地模型估算，无论指南针选择磁北还是真北都显示；它不是测量成果。

卫星天空图只绘制设备通过 `GnssStatus` 报告的卫星，不下载星历、不调用卫星目录、不推算完整星座。默认北上、南下、东右、西左，并可让图面跟随设备方向旋转。选中卫星显示缓慢旋转的断开十字；排序可按载噪密度比或自定义公司顺序。系统名称和卫星编号在界面使用中文。真实手机能否同时接收中国北斗、美国定位系统、欧洲伽利略、俄罗斯定位系统等，取决于芯片、天线、地区、天空遮挡和系统实现。

切页、锁屏和后台时默认暂停卫星接收，返回状态页后重新注册；用户可改为停止。暂停/停止只针对状态页的卫星监听，不改变持续定位前台服务。地点存储不设应用层数量上限，数据仍只保存在本机，受手机存储和 JSON 文件大小限制。

电池瞬时电流采用 Android `BatteryManager.BATTERY_PROPERTY_CURRENT_NOW`，应用将系统值反号后显示，以统一为正值表示放电、负值表示充电；厂商可能不提供该字段或采用不同符号约定。电池健康直接转述 `EXTRA_HEALTH` 的系统枚举，不等于容量测试或安全保证。

重力传感器是系统估算并滤除线性运动后的重力方向；含重力的加速度计同时包含重力和设备运动加速度；线性加速度是系统尽量去除重力后的运动分量。三者用途不同，数值会受校准和系统融合算法影响。

本版不新增在线数据源、地图、星历、第三方运行时依赖或权限，不使用 GPS Status 的闭源代码、资源、SDK 或服务。官方接口参考及限制见 [STATUS-1.2.0](STATUS-1.2.0.md) 与 Android 官方文档。
