# pre-3.0.0-3

版本：pre-3.0.0-3 / 54。宿主包名及原签名不变，稳定正式版为 2.2.1。

## 更新

- 内部应用显示名称改为“音乐”“设备通信”“色觉模拟器”，稳定身份、资料目录和蓝牙服务标识不变。当前标题、通知、设置及中英文说明同步，历史独立版保留原名。
- 天文、音乐、天气地图、色觉模拟器、状态、设置、地震、课程表采用用户指定图片；原图按字节保留，显示资源统一天气图标的圆角及透明留白。天气云朵与背景、商店提绳与背景的对比度提高；随机骰子重画为正方形，待办下方改为灰色空心方框。13 个入口总览与素材说明同步。
- 音乐选择文件夹后在后台扫描，显示当前文件名、进度和取消入口；批量导入完成显示成功、非音频跳过及失败数量。取消清理未完成副本，保留原文件和已导入歌曲。
- 音乐统一文件筛选，跳过歌词、图片、文档等非音频文件；复用目录和曲库索引，避免重复资料读取与主线程逐首重读整份曲库，大量歌曲分批显示。
- 搜索支持逐首勾选、全选匹配结果及资料编辑，与“我的歌曲”共享勾选状态。折叠分类的匹配歌曲也可全选，跨分类的同首歌曲同步选择，编辑后重新查询。
- 应用商店安装完成及目录刷新保留滚动位置，本地文件安装也采用相同更新路径。
- 更新中英文跨应用提示，保留历史更新记录以及实际网页、设置子页面的准确称呼。

## 应用包

11 个签名执行包位于 `modules/store/pre-3.0.0-3/`，绑定 `daidai-toolbox/pre-3.0.0-3` 宿主 ABI，内部包版本代码为 3。默认安装天气和状态，设置与商店固定；其他应用按需安装。旧内测版执行包需换成本版包，保留资料不删除；卸载状态不擅自重置。旧目录独立保留。

## 验证与边界

验证结果见 [TESTING.md](../TESTING.md) 及交付目录中的记录。本版复用已核查数据来源，不新增运行时依赖。图标原图与显示资源哈希见 `modules/icons/assets.json`。

原版已过滤常见非音频文件，不能认定用户原始卡顿仅由混合文件夹导致；本次检查覆盖重复遍历、曲库访问和大量条目创建。未取得用户故障目录，系统音频资料读取器及各厂商文件提供方仍可能受损坏文件、设备速度影响。文件名进度便于定位慢文件。

保留安装签名信任、数据覆盖、文件授权、隐私、测量限制及后台系统限制说明，因为这些内容影响用户选择。实体蓝牙双机、厂商后台策略及各设备相机、传感器、音频解码器不以模拟器结果代替实测。
