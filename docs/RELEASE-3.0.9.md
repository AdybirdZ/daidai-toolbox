# 呆呆工具箱 3.0.9 版本说明

3.0.9 / versionCode 66。改进应用商店中的工具箱本体更新检查与下载流程：优先读取官方公开清单，GitHub API 作为回退；清单包含签名证书指纹，并校验官方 APK 地址、大小、SHA-256、包名、版本代码与原签名。检查按 versionCode 识别同名修订。最近的有效检查结果可在短时网络故障时使用，自动检查节流而手动检查立即重试；旧于当前版本的远端清单不会触发降级。下载前检查可用空间，网络中断或取消后可续传匹配的部分文件，完整下载后仍验证哈希和签名。验证通过的安装包保存到公共 `Download/DaidaiToolbox/`，由用户使用系统文件管理器手动确认安装；不再请求应用内安装权限或自动安装。重复检查会复用同名且校验正确的已下载文件。

本地自动测试和构建通过后，请人工验证：

- 在 3.0.8 中打开应用商店，检查并下载 3.0.9，确认安装包出现在 `Download/DaidaiToolbox/`，再用系统文件管理器手动确认覆盖升级和原有资料保留。
- 断网打开应用商店，查看有效缓存提示；再恢复网络并手动检查，确认可以立即刷新。
- 多次自动进入商店，确认检查节流；点击“检查工具箱更新”应立即重新检查。
- 模拟低存储空间、取消或中断下载，确认提示原因清楚；可续传时继续下载，并确认最终安装包校验通过。
- 在隔离测试条件下验证错误清单、错误 SHA-256、错误证书指纹和旧版本清单均不会提供安装或降级。
- 发布核验：`python scripts/verify-host-update.py --remote` 已从 GitHub 公开清单下载 Release APK，并核对包名、版本、证书及哈希一致；远端 APK 也已在隔离模拟器安装成功。

本地 review 构建已通过自动检查；公共下载目录写入、系统文件管理器打开和覆盖安装仍需在实际设备人工验证后再覆盖现有正式 3.0.9 Release。
