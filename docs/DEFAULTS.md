# 1.2.4 默认设置

- 描边：关闭（默认）；描边颜色：黑色（默认）。旧版显式保存的描边开关不强制覆盖，未保存开关时采用新默认值。
- 背景：不导入图片（默认）；亮度：20（默认）。
- 定位：GPS 硬件定位（默认）；网络定位间隔：5 秒（默认）；切换栏目和后台继续定位：关闭（默认）。状态卫星天空图跟随设备转动（默认），回到状态页面自动继续卫星接收（默认）。路线绘制间隔：5 秒（默认），范围 2～60 秒，网络定位遵循定位回调间隔。
- 状态栏目默认全部显示，依次为指南针、当前位置、定位卫星、地点、路线绘制、传感器、电池、设备与环境、使用说明；路线绘制在地点下方、传感器上方。已自定义的排序保留。非 GPS 状态显示目标刷新周期为 50 毫秒（20 次/秒），定位请求间隔保持原设置。
- 天气地图：全国雷达（默认）。
- 49 颗恒星、七个行星、15 个深空中心：显示方式默认手动选择，默认全部显示；北斗七星也可设置和点选。按星等模式默认上限 6.0 等，范围 -2.0～8.0、步进 0.1。太阳和月球不受该筛选影响。天球坐标默认为地平坐标系。
- 天气栏目：全部显示及原始顺序（默认）。底部显示天气、课程表、状态、地震，隐藏天气地图、天文（默认）；原始排列为天气、课程表、状态、天气地图、天文、地震，升级时在旧排序末尾追加地震。
- 课程信息前缀：地点显示“地点：”、名称显示“课程名称：”、教师显示“教师：”（默认）。三个前缀设置的默认选项均排在首位；旧偏好值含义保持。新课程每周、晴蓝色（默认）。
- 学期：开始于本周周一（默认），17 周（默认）；12 节苏州大学课程时间（默认）。

升级读取已保存的完整课表，不自动改写旧学期、节次或自定义时间；没有已存课表时使用新默认。点击“一键恢复默认设置”后采用本表；若已有课程涉及第 18 周以后或第 13 节以后，保留课程所需的范围，必要时保留与额外节次相兼容的旧时间，避免课程失效。课程与收藏不删除。

天文栏目默认全部显示，依次为时间控制、观星条件、当地星空、选中的星星信息、月球信息、日月与行星位置、当天日月事件与曙暮光、流星雨、计算说明与来源。设置在天文栏目内即时保存；恢复默认也会重置它们。版本记录的展开状态不持久化。

地震默认：最近 7 天、全球范围；全球与中国及周边最低均为 M≥1.0（滑块 0.0～7.0、步进 0.1），按最新发生排序、手机时区（实际 UTC 偏移在数据来源与隐私显示）；只采用 MMI，参数满足条件时估算，模型及假设在详情显示；15 分钟前台刷新；使用定位位置作参考，附近半径 1000 km（选“参考位置附近”才显示输入框，可输入 50～5000 整数）。所有列表字段和三个栏目均显示，顺序为筛选与刷新、更新状态、地震列表。德国地学研究中心、欧洲—地中海地震中心和美国地质调查局开启；Wolfx 默认关闭，旧版开关不能绕过本版确认。查询门槛不是完整收录承诺。

已保存的自定义震级、时间范围、区域、参考坐标和其他设置保留；旧数据说明栏目已移入关于，不再参与栏目排序。一键恢复默认会清除 Wolfx 本版确认状态。

1.1.4 移除烈度标度选择及旧偏好，一律使用 MMI。本地优先论文模型，其保守条件外用 GlobalQuake 参考算法，不为缺失深度假定数值。地震刷新区仅刷新目录与定位位置模式下的刷新定位；其他筛选入口只在设置 → 地震内。状态显示为已复核、自动结果、状态未知；详情保留来源具体标记。坐标显示统一经度、纬度及 E/W/N/S，手动输入保持十进制度正负号。

历史 1.1.5 曾仅依靠固定竖屏；1.1.6 手机保留竖屏请求、平板适应横竖屏，并在配置变化和任务恢复时保存状态。地震合并主要参数按中国地震台网已复核、其他已复核、自动结果或状态未知依次选择；同级取较新来源更新时间，不再给予德国来源额外优先级。该规则没有改变来源开关默认值。

- 状态 1.2.0：原定位栏目 ID 2 改名状态；默认全部 8 个区域显示，顺序为指南针、当前位置、定位卫星、地点与寻宝、传感器、电池、设备与环境、使用说明。指南针默认磁北，所有卫星系统默认显示；卫星接收须主动开始，默认不自动启动。地点初始为空，独立存储，恢复默认设置与清缓存保留。原持续定位默认关闭。

- 状态 1.2.2：传感器默认全部显示，默认顺序保持系统传感器列表；采样由系统使用尽可能高的频率，设置中不再提供帧率选项。卫星天空图默认跟随设备转动，明细默认按公司排序，公司顺序为中国 BDS、美国 GPS、欧洲 Galileo、俄罗斯 GLONASS、日本 QZSS、印度 NavIC、其他系统。切换栏目、锁屏和后台默认暂停卫星接收，回到状态页面自动继续；地点不设数量上限；电流默认使用系统原始符号。电池和设备信息默认全部显示，顺序与状态页默认栏目一致。


## pre1.2.5 本地预览

默认值及设置键保持不变。卫星排序的界面名称改为“按卫星系统排序”，时间显示的默认选项改为“自动（默认）”。默认时区及生效范围详见设置中的说明；文字与段间距规则见 [预览调整说明](TEXT-pre1.2.5.md)。预览安装包及源码包可直接覆盖，无需另存备份。

## 1.2.5 地点与状态交互

新增地点默认蓝色并在地点图中显示；旧地点按相同默认值迁移，不修改经纬度。定位及卫星接收默认仍未启动，开始卫星接收将同时开始当前位置更新；持续定位开关仍默认关闭。回放居中后跟随橙色回放点，平移取消跟随。
