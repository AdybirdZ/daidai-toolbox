# 1.1.4 默认设置

- 描边：关闭（默认）；描边颜色：黑色（默认）。旧版显式保存的描边开关不强制覆盖，未保存开关时采用新默认值。
- 背景：不导入图片（默认）；亮度：20（默认）。
- 定位：GPS 硬件定位（默认）；最短请求间隔：5 秒（默认）；切换栏目和后台继续定位：关闭（默认）。
- 天气地图：全国雷达（默认）。
- 亮星、七个行星、两处深空中心：默认全部显示；北斗七星固定按地平线可见性显示。天球坐标默认为地平坐标系。
- 天气栏目：全部显示及原始顺序（默认）。底部显示天气、课程表、定位、地震，隐藏天气地图、天文（默认）；原始排列为天气、课程表、定位、天气地图、天文、地震，升级时在旧排序末尾追加地震。
- 课程信息前缀：地点显示“地点：”、名称显示“课程名称：”、教师显示“教师：”（默认）。三个前缀设置的默认选项均排在首位；旧偏好值含义保持。新课程每周、晴蓝色（默认）。
- 学期：开始于本周周一（默认），17 周（默认）；12 节苏州大学课程时间（默认）。

升级读取已保存的完整课表，不自动改写旧学期、节次或自定义时间；没有已存课表时使用新默认。点击“一键恢复默认设置”后采用本表；若已有课程涉及第 18 周以后或第 13 节以后，保留课程所需的范围，必要时保留与额外节次相兼容的旧时间，避免课程失效。课程与收藏不删除。

天文栏目默认全部显示，依次为时间控制、观星条件、当地星空、选中的星星信息、月球信息、日月与行星位置、当天日月事件与曙暮光、流星雨、计算说明与来源。设置在天文栏目内即时保存；恢复默认也会重置它们。版本记录的展开状态不持久化。

地震默认：最近 7 天、全球范围；全球与中国及周边最低均为 M≥1.0（滑块 0.0～7.0、步进 0.1），按最新发生排序、手机时区（实际 UTC 偏移在数据来源与隐私显示）；只采用 MMI，参数满足条件时估算，模型及假设在详情显示；15 分钟前台刷新；使用定位位置作参考，附近半径 1000 km（选“参考位置附近”才显示输入框，可输入 50～5000 整数）。所有列表字段和三个栏目均显示，顺序为筛选与刷新、更新状态、地震列表。德国地学研究中心、欧洲—地中海地震中心和美国地质调查局开启；Wolfx 默认关闭，旧版开关不能绕过本版确认。查询门槛不是完整收录承诺。

已保存的自定义震级、时间范围、区域、参考坐标和其他设置保留；旧数据说明栏目已移入关于，不再参与栏目排序。一键恢复默认会清除 Wolfx 本版确认状态。

1.1.4 移除烈度标度选择及旧偏好，一律使用 MMI。本地优先论文模型，其保守条件外用 GlobalQuake 参考算法，不为缺失深度假定数值。地震刷新区仅刷新目录与定位位置模式下的刷新定位；其他筛选入口只在设置 → 地震内。状态显示为已复核、自动结果、状态未知；详情保留来源具体标记。坐标显示统一经度、纬度及 E/W/N/S，手动输入保持十进制度正负号。
