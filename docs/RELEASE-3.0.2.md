# 3.0.2 · 内部应用导航与外观

- 音乐、设备通信和色觉模拟器增加底部桌面按钮，打开这些应用和设置时直接显示内容。
- 设置使用顶部返回箭头和底部桌面按钮。统一三个内部应用的普通按钮配色、描边与设置布局。
- 本机配对码可跨会话使用。未连接且未等待连接时，可手动刷新。配对码保存在设备上，不随导出的通信资料转移。
- “设置 → 状态 → 传感器”增加进入状态时自动开启相机环境光测量的开关，默认关闭。使用系统光传感器时不启动相机。
- 核对课程提醒的系统倒计时、上课后的状态切换和通知移除。在 Android 15 标准通知模板上验证了倒计时控件可见并自行变化。各厂商通知界面的实际呈现需在对应设备上确认。
- 未来计划增加小球淘汰赛。

安装宿主后，在工具箱的应用商店点击“全部更新”取得已安装应用的新版本。
