# 状态页 · 1.2.2

1.2.2 继续使用 Android 官方 `SensorManager`、`GnssStatus`、`LocationManager`、`BatteryManager` 和设备存储接口，不新增在线卫星、地图或第三方运行时依赖。状态页仍只显示设备实际报告的数据；卫星高度角、方位角、载噪密度比和参与定位标记受手机芯片、权限、天空遮挡和厂商实现影响。

## 接收与生命周期

状态页切换栏目、锁屏或进入后台时按“回到状态页面自动继续卫星接收”设置暂停卫星回调；默认开启，回到状态页面立即重新注册。关闭该设置后，离开状态页会停止接收，需要再次点击开始卫星接收。这个设置只管理状态页卫星接收，不改变用户主动开启的持续定位前台服务。持续定位默认关闭，仍需主动开始，并受系统省电、权限和厂商后台策略影响。

应用固定竖屏，避免平板配置变化导致页面重建、当前栏目或地震获取状态变化。系统仍可能因进程被杀、强制停止或权限变化清除运行时对象；本机设置和地点按应用存储规则保留。

## 栏目、排序和采样

状态设置按页面默认顺序列出指南针、当前位置、定位卫星、地点、传感器、电池、设备与环境、使用说明；三个生命周期开关放在设置末尾。传感器、电池和设备信息均可逐项关闭并用箭头排序，状态页按照保存顺序绘制。传感器帧率设置已移除，应用请求 `SENSOR_DELAY_FASTEST`，实际采样频率仍由硬件和系统调度决定。

电池瞬时电流可选“系统原始符号（默认）”或“反转符号”。Android `BATTERY_PROPERTY_CURRENT_NOW` 的正负定义由设备实现决定，不同厂商定义不同；应用不会把缺失字段伪造为零。健康状态只反映 `EXTRA_HEALTH` 的系统报告，不等于容量检测或安全保证。

## 卫星名称和限制

卫星名称采用国家或地区加英文缩写，例如“中国 BDS”“美国 GPS”“欧洲 Galileo”“俄罗斯 GLONASS”“日本 QZSS”“印度 NavIC”。星座名称来自 Android `GnssStatus` 的常量，星号编号来自设备芯片报告；应用不下载星历、不推算完整星座，不代表所有可见卫星。

## 地点

保存地点的年龄每秒按最近定位的真实时间更新。编辑地点时可点击“重新定位”，按状态设置中选择的 GPS 硬件或网络方式单次请求位置，只填写当前表单经纬度，不自动修改已经保存的地点。经纬度和地点名称仅保存在本机；权限、系统定位服务和网络定位服务商的隐私规则仍适用。

状态页不提供专业测绘、导航、安全决策或无线电发射功能。详细来源和隐私说明见“设置 → 关于 → 数据来源与隐私”。
