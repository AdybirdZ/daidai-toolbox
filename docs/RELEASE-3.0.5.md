# 呆呆工具箱 3.0.5

3.0.5 / versionCode 61。包名 `org.simpleweather.app`、原签名和 `daidai-toolbox/api-1` 保持不变。11 个内部应用包为 3.0.5 / versionCode 10，要求当前宿主版本代码至少为 61。

## 更新内容

- 蛇夫座 α 星显示为“侯”，勾陈一使用规范名称，不再附加别名括注。
- 新增五车一和壁宿一。恒星设置列表按照视星等由亮到暗排列，并保留稳定身份、来源和许可记录。
- 当地星图使用图下缩放滑块，左侧缩小、右侧放大，关闭双指缩放。单指可平移星图，缩放不改变星点和对准标记的屏幕尺寸。对准方向位于视野外时显示红色实心三角箭头。
- 点击范围内存在多个天体时显示候选列表。星图拥挤时先显示较亮天体名称，放大后逐步显示较暗天体名称。选中天体信息显示升落时刻，全天位于地平线上方或当天未升起时显示相应状态。
- 状态中的路线缩放滑块改为左侧缩小、右侧放大。
- 各应用底部“桌面”按钮统一尺寸、间距和圆角，描边上沿完整可见，并随系统文字大小自适应高度。
- 音乐、设备通信和色觉模拟器接入工具箱背景，系统栏显示为透明，页头统一使用工具箱应用的标题与副标题格式。

## 数据与验证

星名、HIP 对应关系、坐标、视星等、来源版本及许可见 [3.0.5 天文资料](ASTRONOMY-3.0.5.md) 和 [JSON 记录](ASTRONOMY-3.0.5.json)。本地核心测试和中英文资源检查由 `scripts/test.ps1` 执行。实体设备、真实传感器和厂商后台策略仍需按设备实际情况验证。
