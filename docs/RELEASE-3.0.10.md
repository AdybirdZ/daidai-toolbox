# 呆呆工具箱 3.0.10 发布说明

本版将 Java 源码目录和命名空间迁移到 `org.daidai.toolbox`，同时保留 Android 安装身份 `org.simpleweather.app`、原签名和用户数据目录，因此可以作为现有安装的覆盖更新。内部应用重新构建为 `daidai-toolbox/api-2`，以反映二进制类名变更。

为兼容升级前创建的系统引用，Manifest 保留旧 `MainActivity` 的 Activity 别名，并保留旧 `TodoReceiver` 的私有转发入口。课程和待办提醒的新代码仍使用新命名空间；旧快捷方式、闹钟和通知操作不应因源码路径迁移而失效。旧 receiver 类是刻意保留的 Android 系统兼容符号，不是当前业务代码命名空间。

真实厂商后台限制、系统时间/时区变更、旧设备上已经存在的通知操作 PendingIntent 尚未在实体设备上验证。模拟器没有真实 GPS 坐标更新；真机定位、传感器帧率、真实音乐目录和设备通信仍未验证。自动测试通过不等于所有设备场景均无 bug。
