# 呆呆工具箱 2.2.1

版本名称 2.2.1，versionCode 51，包名 `org.simpleweather.app`，沿用原签名。该版本修复导航保留及权限设置入口，不改变用户长期资料格式。

## 行为变化

桌面快捷方式原先使用 `NEW_TASK | CLEAR_TOP`，而主 Activity 使用标准启动模式；再次点击可能销毁既有 Activity，丢失它拥有的对话框和草稿。主入口改用 `singleTop`，新快捷方式另加 `SINGLE_TOP`，旧快捷方式也能按清单规则复用已有实例。正常 Home 后返回保留原设置层级、编辑内容和滚动。配置导入仍需要重新构建页面，采用 `recreate()` 显式完成。

权限与系统限制页集中管理应用权限、通知、准时提醒、系统定位、桌面快捷方式、电池优化及禁止系统休眠。快捷方式没有通用的专用权限 Intent，因此提供应用与桌面设置入口并说明厂商差异；回退不代表已授权。保持屏幕亮起仅作用于前台窗口，不改变后台传感器、定位或相机授权。

短暂提示统一移除末尾单个中英文句号；省略号和多行、较长错误详情保留。中文与英语 XML 同步维护。

## 验证结果

工作区核心入口通过，包含 3731 项主核心检查及既有模型套件；新增 `TransientTextTests` 的 11 项通过。1694 条中文/英语 XML 资源的键、占位符及引用检查通过。API 35 隔离模拟器 `Release221UiTests` 中文、英语各 28 项通过，覆盖旧快捷方式返回、设置层级、未保存待办草稿及光标/滚动、状态栏目与前后台传感器行为；`ConfigurationUiTests` 的 27 项通过，覆盖实际配置导入导出、重建与地区搜索。2.2.1 APK 已用原签名构建通过；发布资产及远端哈希由实际发布流程核对。详见 `TESTING.md` 和本版本交付记录。

## 范围与限制

真实进程死亡或系统强制重建时，栏目和已有专用状态恢复沿用原逻辑；任意编辑器的未保存草稿尚未提供统一序列化契约。本次修复不会通过后台持续采集来保留界面。快捷方式系统设置路径因设备和启动器而异，不能保证所有厂商提供独立权限入口。

本次未在实体设备验证，未执行杀进程后草稿恢复，也未遍历全部权限页面。按开发者准则保留的必要说明包括快捷方式权限差异与回退、前台保持亮屏的作用边界，均放在对应具体设置底部，避免误示授权或后台保活。

未来 3.0.0 审查建议见 `PRE3.0-MODULE-REVIEW-DRAFT.md`，本版不修改未来宿主或宣称已实现内部应用安装、卸载。
