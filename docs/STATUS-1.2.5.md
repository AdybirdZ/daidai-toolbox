# 状态页 · 1.2.5

本版合并 pre1.2.5 的文字和段落排版优化，保留现有课程、地点、路线及设置。

路线回放时，点击“以当前位置为中心”后持续跟随橙色回放点，暂停后仍保持居中。缩放不会取消跟随，手动平移会取消跟随。实时记录时，该按钮仍以设备定位位置为中心。点击邻近或重叠记录点后，选择列表保持打开；从详情点击“返回”或系统返回键，可继续选择其他记录点。

当前位置与卫星接收分别使用一个开始／停止按钮。开始卫星接收会同时启动实际定位服务，定位方式采用状态设置；开启持续定位后可直接开始路线绘制。停止卫星接收保留定位服务，停止定位则同时停止卫星接收。离开状态页面后的接收与定位行为仍由各自设置决定。垂直定位误差半径位于海拔下方，与水平定位误差半径采用相同的大字显示。

新增或编辑地点时，可选择八种颜色并设置是否在地点图中显示。地点管理中可直接切换显示状态。地点图同时绘制所有可见地点，圆环表示所选目标，点击地点可更换目标；邻近地点可从列表中选择。隐藏只影响图中显示，不删除地点或清除目标选择。外圈比例按可见地点的最远距离自动调整。旧地点默认蓝色并显示，经纬度和标识保持不变。

沿用原包名、签名、权限与本地存储，没有新增网络数据源或第三方运行时依赖。versionName 为 1.2.5，versionCode 为 28；安装包和源码包仅在本地交付，未上传 GitHub。
