## 数据、坐标与许可

新增事实来自 Wikidata 主命名空间的结构化数据，按 [Wikidata 许可说明](https://www.wikidata.org/wiki/Wikidata:Licensing)及 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)使用。CC0 允许本次非商业使用；本版无需天文 API 授权，不增加运行时请求。完整事实表和实体、星等声明 ID 见 [SKY-CATALOG-1.1.6.json](SKY-CATALOG-1.1.6.json)。经官方实体 API 核对 P6257/P6258 为角度坐标、P6259 为 J2000.0，P1215 的 P1227 限定为 V 波段 Q4892529。没有把红外、B 波段或 Gaia 星等混入 V 波段筛选。

原昴星团与仙女座星系坐标沿用 1.0.9 已核实的记录及修订号；本次补上 V 波段参考总视星等。其他天体只保留数值、名称、许可、实体与声明来源，不把未请求的 API 修订号编造为已核对版本。研究响应留在本地工作目录，应用不带整个 Wikidata 实体库。

固定坐标是 J2000 近似值，未新增岁差、自行或高精度折射；星等为静态参考，变星和复星测量口径可有差异。行星仍使用现有离线模型按所选时间估算。深空位置只代表大致中心，标记大小不是实际角直径。模型不用于精密指向。

## 两种显示方式

默认手动选择，保留已有 astro_star / astro_planet / astro_deep 开关。北斗七星现在与其他恒星一样可选、可隐藏；默认显示。太阳和月球不参与这组星等筛选。

按星等上限模式以目标星等 ≤ 上限作为条件：范围 -2.0～8.0，步进 0.1，初始上限 6.0。数越小越亮，支持负星等，临界相等包括在内；未知星等不假定符合门槛。两种模式相互独立，切回手动恢复原开关。行星用天文页面所选时刻的估算星等；筛选设置不改变星点选中，隐藏或落到地平线下只暂停绘制十字。

深空总视星等表示整个扩展目标的综合光度；相同总星等下，光分布越分散，表面亮度可能越低，因此总星等亮不等于肉眼容易看到。设置和详情都给出该说明。筛选不新增未内置星点，也不是光污染或能见度模型。
