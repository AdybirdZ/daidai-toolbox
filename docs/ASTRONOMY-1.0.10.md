# 1.0.10 星空、标签与月球

## 布局与选择

星图 View 按可用宽度测量成正方形，坐标外圆半径最多为边长的 43%，按实际字号为方向/赤经字留出边距，小屏放大字体时不会贴边裁切。地平、赤道和无网格模式都采用同一尺寸。图中天体仍仅绘制在当地地平线上方。

星点标签以自身为中心，优先放在上方 8dp 基线位置；按屏幕 y 从小到大处理，因此位置较高的点先放标签，较低的点遇冲突时改到正下方。上下两处文字到点的可见间隔相同；两处都与坐标文字/已有标签冲突或越界时不显示标签。没有额外远距离候选位置，也不强制挪动选中标签；选中十字与命中区域仍保留。流星雨标签也遵循这两处候选位置。

“选中的星星信息”支持既有恒星、行星、深空中心，并新增太阳/月球。太阳不显示星等。月球使用包含地心视差修正的同一方向参与绘制、命中、赤道投影与高度/方位详情，避免画点与点击区域错位。时间修改后选中保留；隐藏/地平线下处理延续 1.0.9。

## 月球视星等与来源核查

参考已有的 [Paul Schlyter：How to compute planetary positions，第 15 节](https://stjarnhimlen.se/comp/ppcomp.html#15)，2026-10-25 直接访问 HTTP 200，核实月球公式：

`V ≈ −21.62 + 5 log10(r × R) + 0.026 α + 4×10⁻⁹ α⁴`

其中 α 为月球相位角（度）；r 近似使用日地距离（AU），R 为地月距离（地球半径）。相位角用日月赤经/赤纬算出的球面夹角求得，距离由本应用既有轨道计算获取。仅以科学数学方法和少量公式常数为参考，Java 代码独立编写；没有复制网页正文、第三方代码、照片、图表或抓取星等数据库，也不增加 API 调用或数据服务条款。原参考网页不是被声明为整站公有领域，其表达、代码和素材的权利不因本实现而改变。

显示为“视星等约 …（V 波段估算）”，不是观测值。经验式忽略月食、地球照、大气消光等，相位角 ≥170°（近新月）时不外推，改为“近新月，暂不估算”。不能用来预测月食时亮度、肉眼能否看见月牙或精密测光。公式参考链接保留在天文页面底部。

## 独立月球信息

在“日月与行星位置”上方新建“月球信息”：月相、照亮比例、近似月龄和距下次满月时间集中显示。月相图由本地 Canvas 与球面照明关系绘制，不使用外部图片。

图像采用北上示意约定：盈月右侧亮，亏月左侧亮；按所选日期时间的月相更新，按“当前”即使用当前时刻。未考虑当地视角旋转、月面纹理或月食，不是现场月球朝向模拟。亮区面积与本应用照亮比例一致，核心测试验证新月、上弦、满月、下弦及中间相位。月龄和下次满月仍按平均朔望月折算，为近似时间，不是精确事件预报。
