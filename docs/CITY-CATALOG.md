# 中国城市目录

核对日期：2026-10-31。目录代表城市或政府驻地的天气查询点，不是边界数据，也不表示行政范围内所有地点具有相同天气。

## 范围与数量

- 大陆 4 个直辖市、293 个地级市、398 个县级市，共 695 个城市。
- 台湾 23 个市；香港、澳门各 1 项。
- 苏州 5 个行政区及苏州工业园区，共 6 项。
- 用户旧名单中已撤市设区的 13 项，使用现行区名，并以原市名作为搜索别名。
- 合计 739 个中国目录条目；另有 6 个原有海外代表地点。地区选择页只显示收藏和搜索，不展示预置长列表。

不以自治州、地区或盟本身作为城市结果。甘孜藏族自治州条目移除，康定市保留；这不把自治州称作自治区。目录包含县级市，区县在线搜索仍可使用。

## 覆盖核查

1. [民政部统计数据入口](https://www.mca.gov.cn/n156/n2679/index.html)及[2025 年民政事业发展统计公报](https://www.mca.gov.cn/n156/n2679/c1662004999980013510/attr/468811.pdf)，行政区划表：4 个直辖市、293 个地级市、397 个县级市。
2. [2026 年设立草湖市的新疆政府公告](https://www.xinjiang.gov.cn/xinjiang/tzgg/202604/3691350b13064945947d8f78933ccb3e.shtml)，2026-04-17，明确市政府驻草湖镇；县级市总数据此增加为 398。
3. [行政区划基础名录](https://github.com/modood/Administrative-divisions-of-China)，基础数据截至 2023-06-30，不宣称该数据本身为 2026 年官方全量。去除“不设区的市”同名下级统计行，并核对后续变化。
4. [城市列表核对入口](https://zh.wikipedia.org/wiki/中华人民共和国城市列表)与[台湾行政区划核对入口](https://zh.wikipedia.org/wiki/臺灣行政區劃)。只用于事实交叉核查、查找政府原始链接与 Wikidata 身份，未复制百科正文。

台湾按 6 个直辖市、3 个市及 14 个县辖市整理，共 23 市；补充旧名单遗漏的头份市、员林市，两市于 2015 年改制。两市公所网站本轮连接失败，逐项审计保留对应官方引用链接，以已读取的 GeoNames、Wikidata 及百科引用交叉核查身份和坐标。

用户旧名单中的双鸭山重复项仅保留一次。藁城、鹿泉、冀州、龙海、金坛、海门、普兰店、莱芜、即墨、蓬莱、偃师、潞城、奉化使用现行区名。津市的正式名称是“津市市”，芒市不额外拼接一个“市”。不把同音的苏州/宿州、泰州/台州等混合。

## 坐标与身份

[逐项 CSV](CITY-CATALOG-1.2.10.csv)及[含核查链接的 JSON](CITY-CATALOG-1.2.10.json)记录每项名称、层级、所属区域、行政代码、坐标、GeoNames ID、补充来源与匹配方法。

使用 GeoNames 中国及台湾、香港、澳门离线转储，按真实中文名称、所属省份、地物类型及独立坐标交叉选择；不靠拼音搜索首项自动发布。优先城镇或政府驻地，避免行政区范围中心。GeoNames 对部分城市的行政归属或名称存在滞后，因此不机械使用其 admin2 字段或仅选择 PPLA2。

与 Wikidata P1566 对应的 GeoNames 行用于核对同一行政实体。无适用城镇坐标时使用 Wikidata P625 结构化坐标；部分地点采用其政府驻地的结构化坐标。草湖市采用 OpenStreetMap 草湖镇代表点，官方公告用于确认驻地身份。没有把缺失的 GeoNames ID 虚构出来，也不声称每个新增市已在 GeoNames 有独立城市条目。

典型冲突：图们市的一个百科坐标写到东经 118°，与吉林的 GeoNames 记录及 Wikidata 不符，采用约 129.84°E；龙南市的独立参考纬度多写约 1°，采用 GeoNames 城镇记录约 24.90°N；山南采用泽当城市点，茫崖采用花土沟驻地，洪江采用黔城驻地，不采用同名旧镇或大行政范围中心。

目录、收藏、当前地区和在线搜索按稳定行政身份、GeoNames 标识或受省份和近距离约束的明确别名统一。不同省份、城市与县区不因接近或删去全部行政后缀就合并。自动化检查覆盖全目录唯一性、来源 ID 不交叉、分类总数和重点错误坐标；这不能等同于测绘级坐标精度保证。

## 天气覆盖

Open-Meteo 预报 API 以经纬度查询，不要求地理编码 API 存在相同市名。因此“GeoNames 缺少城市条目”不等于“没有该城市坐标的天气”。使用各目录点即可请求模型预报；模式格网、模型覆盖及服务可用性仍适用官方限制。没有逐个调用 739 次天气接口，也不声称逐点联网实测成功。
