# 状态页 · 1.2.3

## 路线绘制

路线绘制使用本机状态页已经获得的定位结果，不连接地图或路线服务。开始前必须打开“切换栏目和后台继续定位”并点击开始定位；这样切换栏目、锁屏或进入后台后，位置服务仍可继续工作。路线记录默认每 5 秒取一个点，可在“设置 → 状态 → 路线绘制间隔设置”中用滑块改为 2～60 秒。网络定位时，记录间隔不能短于网络定位设置；如果系统定位回调更慢，应用只在收到真实回调时记录。

每个点保存经度、纬度、系统定位时间和可用的水平误差半径。定位失败或暂时没有新回调时暂停添加点，恢复信号后自动继续，不用 0,0 或插值点填补。绘制按钮在“开始绘制”和“结束绘制”间切换，右侧为“以自己为中心”。路线画布始终接受单指拖动并阻止外层页面抢走手势，使用下方缩放滑块（0.25～64 倍），双指不缩放。点按记录点查看序号、经纬度与记录时间；多个点重叠或邻近时显示序号列表供选择。结束后可输入名称保存或删除，名称输入框保留左右空隙；未保存记录只在当前运行内存中保留。

选择保存的路线会关闭列表，并在路线框中完整预览。列表入口下方显示“跳到开头 / 上一个 / 播放或暂停 / 下一个 / 跳到最后”按钮，以及 1～20 个记录点/秒的速度滑块。首次播放或在终点重新播放时从第一个点开始，之后只显示当前点及此前的点和连线。暂停时才允许跳转，跳转后以相应记录点为中心。播放期间可以拖动和缩放视角；到达终点自动暂停，离开状态页面也暂停回放，返回后可从当前点继续。回放与位置服务独立，不重新生成定位点，不修改保存的数据。保存路线使用本机 JSON，不会上传。

路线存储量与定位点数量成正比，每个点只包含少量数值字段；长时间高频记录仍会增加手机存储占用。清除缓存不会删除保存的路线，恢复默认设置也保留路线；卸载应用会删除本机路线。

## 其他状态页调整

俯仰和横滚在指南针区域以大字显示：屏幕上方向天上为正俯仰，横滚向左为负、向右为正。状态页方向说明统一采用“上北下南左西右东”。普通说明文字不允许长按选取；输入框仍按 Android 输入控件规则工作。

设置中的背景、描边和时间显示集中到“全局设置”。时间显示选择会同步地震和天文等使用时区格式的页面；天气预报仍按所选地区和天气数据中的当地时区展示。定位时间间隔入口改名为“网络定位间隔设置”，用于说明它是系统网络定位请求的最短间隔。

状态页继续只使用 Android 官方定位、传感器、电池和卫星接口，不新增第三方路线、地图或轨迹服务。
