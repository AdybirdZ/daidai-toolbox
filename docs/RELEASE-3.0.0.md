状态：本地验证通过，待发布核对。versionName 3.0.0，versionCode 56；沿用包名 `org.simpleweather.app` 和原签名。正式版核心、中英文设备验证和公开源码独立重建已通过，GitHub 在线安装、标签、Release 及匿名下载核对以实际记录为准。pre-3.0.0-4 / 55 的本地构建和验证记录独立保存。

## 当前功能

11 个完整内部应用通过签名 `.ddapp` 安装到图标桌面，默认安装天气和状态，设置与应用商店固定。原八个应用进一步拆分业务、设置、专用资源、城市目录及通知业务；宿主仍保留小型共用模型、校验契约、全局能力和 Android 组件桥，不宣称所有依赖均完全独立。

稳定接口为 `daidai-toolbox/api-1`，与显示版本分离；固定资源编号只增补、不重排。天文可使用手动参考位置并在无天气资料时继续天体计算，地震可独立请求有时限定位，不要求先打开状态应用。

桌面支持排序、文件夹、图标尺寸、列数、字号及系统桌面快捷方式，手机和平板分别保存布局；应用内底栏只保留桌面。正式版普通按钮采用无阴影样式，保留按压反馈。

商店在原始内容域名不可达时可改用 GitHub 官方内容 API，仍校验哈希与签名。商店提供下载进度、取消、失败重试、批量更新、兼容状态、所需权限和更新说明。签名包更新失败时保留原包，可识别的首次启动失败可恢复前一包。统一资料管理覆盖全部 11 个应用及卸载后保留资料，支持分类占用、单应用导入导出、清缓存和确认删除资料。

支持的设置与待办、课程、地点、文件夹、音乐搜索及歌曲资料草稿可在 Android 恢复原任务时重建；普通冷启动不恢复过期界面，不重放破坏性确认和设备操作。音乐导入提供阶段、耗时、结果记录和失败项重试。

## 正式版调整

正式 3.0.0 取消从旧独立音乐导入资料的专用同机迁移功能，包括入口、对应 ZIP 导入导出和处理路径。当前内部音乐仍参与宿主统一完整备份、恢复和单应用资料导入导出。历史内测版、辅助 APK、源码和说明保留各自适用范围。

正式版已采用普通按钮无阴影样式并保留按压反馈；正式构建和最终交互验证通过，按钮样式与选择控件专项中文、英语各通过 721 项检查。

## 边界与交付

全部内部应用共用宿主进程、UID 和 Android 权限，仅加载受信任签名包，不是权限隔离的第三方插件沙箱。卸载默认保留资料，独立删除资料不删除外部歌曲、歌词或用户导出文件。系统通知、桌面快捷方式、后台和实体蓝牙仍受设备支持及厂商策略限制。
