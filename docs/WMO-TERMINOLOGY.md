# “代码”与“电码”的用词依据

1.0.9 将图例中的 WMO 专业表统一称作“天气电码”“电码表”。“代码”是软件与编码的一般称呼，不能说这个词本身错误；“电码”在气象通信/业务编码表的语境更明确。

官方依据：[WMO 官方 BUFR4 仓库 README](https://github.com/wmo-im/BUFR4#readme)写明，这组表属于 **Manual on Codes, Volume I.2（WMO-No. 306），Part B. Binary Codes**；[WMO 官方天气条目注册表](https://codes.wmo.int/bufr4/codeflag/0-20-003?_view=all)给出 Present weather 的编码条目。当前图例引用的是这种气象业务电码表及其英文条目，而非一般软件代码，故统一用“电码”。本判断不声称 WMO 英语中的每个 code 在中文所有场合都必须译成“电码”。

Open-Meteo 的 `weather_code` 是 API 的数值字段，本应用仍称“天气代码”；解析失败、未知代码等软件行为保留“代码”用词。API 的模型解释与传统观测电码不是处处完全等价，沿用此前核查说明。本版没有把 0–3 等接口标签机械替换成观测电码原义。

图例删去 99 的 heavy 修饰解释段；最后一段以“小或中雷暴伴冰雹”“大雷暴伴冰雹”取代 96/99。底部未知提示改为“正常返回本版本支持的代码……”。
