# 多语言资源维护

2.0.0 起正式支持简体中文与英语。语言入口为“全局设置 → 语言”，可选择跟随系统（默认）、简体中文和 English；不支持的系统语言使用中文。语言选择仅作用于本应用。

## 修改文字

在 `app/src/main/res/values/` 搜索界面原文，按同一资源键同步修改 `values-en/` 中的英语：

- `strings.xml`：应用外壳、通用文字、当前版本记录和格式模板。
- `historical.xml`：历史页面、对话框、图表与旧版本记录。既有键名保持稳定，不因改文案重新编号。
- `identifiers.xml`：不可翻译的历史身份和解析常量，标记 `translatable="false"`。它不是显示文字库，不进入语言目录。

保留 `name`、格式占位符、首尾空格与转义。`%1$s` 表示文本、`%1$d` 表示整数，`\n` 表示换行；自然段统一空一行。完整句子优先使用格式模板，避免新增依赖中文语序的碎片。

## 运行方式

`AppLanguage` 为各 Activity 创建指定语言的资源上下文，默认跟随系统；`LanguagePolicy` 负责稳定选项及回退规则。切换通过 Activity 重建刷新界面，保存当前栏目、滚动位置、天文时间和地震会话，并重新打开同一设置层级。

`ToolboxApplication` 安装共享 `UiText` 提供器。Android 页面使用 `getString`，纯 Java 模型通过 `UiText.get` 动态读取同一套 XML；资源缓存随语言和系统配置失效。栏目、方向和机构名称不得在类初始化时缓存翻译结果。`UiText.raw` 读取稳定数据身份，`UiText.label` 将身份转换成当前显示名称。

`app_language` 偏好使用 `system`、`zh-CN`、`en`，纳入完整配置转移并严格校验。切换不翻译用户资料，不修改 SharedPreferences 键、JSON 字段、URL、机构代码或天体身份。地名、设备名称、第三方站点及来源数据可能保留原文。

## 新增语言与验证

在 `values-语言代码/` 提供全部可译键，扩展语言策略和选择页面，再验证完整覆盖、格式占位符、稳定标识、配置往返及实际界面切换。当前检查支持中英文；新增语言时同步扩展检查。

运行工作区 `scripts/test.ps1` 检查中文行为、英语模型和语言策略；使用 `tests/android/run.py --suite LanguageUiTests` 验证真实语言切换、层级返回、资料保留与配置导入。`EnglishPreviewUiTests` 为沿用的测试类名，目前测试的是正式包中的英语界面。随机抽取套件可通过 `--language zh-CN` 或 `--language en` 分别执行。

旧英文内测包 `pre2.0.0-1` 仅作本地历史材料保留，2.0.0 无需单独安装英文包。其 versionCode 900 高于正式版；个人设备若装有该内测包，应先导出资料，再按设备支持的方式回到正式版，卸载会删除本机应用数据。
