# 多语言资源维护

1.2.13 起已将历史内置界面文字迁移至 Android XML，包括旧页面、对话框、错误提示、图表标签和全部历史更新记录。中文正式版只包含中文界面资源；英文内测包在本地 `work/pre2.0.0-1-source/`，不进入公开 Git 或正式源码包。正式版的语言入口继续说明 2.0.0 计划。

## 修改文字

在 `app/src/main/res/values/` 全局搜索屏幕上的文字：

- `strings.xml`：应用外壳、新增及整理后的通用文字、当前版本记录和格式模板。
- `historical.xml`：从历史 Java 页面迁移的文字和旧版本记录。键名如 `settings_001`、`gps_001`、`update_history_001` 已固定，不因文字变化重新编号。
- `identifiers.xml`：不可翻译的历史标识和解析常量，设置了 `translatable="false"`，不用于直接调整文案。天体名称虽与中文相同，仍可能是保存键的一部分，禁止直接改动。

只改标签中间的文字，保留 `name`、占位符及转义。例如 `%1$s` 是文本、`%1$d` 是整数、`%.1f` 是保留一位的小数。`\n` 表示换行；自然段统一间隔一行。含首尾空格的历史片段外有双引号，须保留，避免拼接后文字相连。修改较复杂的句子时，应改成完整的格式模板，避免新增碎片。

页面中的 `getString(R.string.key)` 和不依赖 Android 的模型中的 `UiText.get("key")` 均读取这些 XML。`ToolboxApplication` 在页面和服务初始化之前装载资源；JVM 测试通过 `TextTestLauncher` 读取同一套 XML。`UiText.raw()` 用于稳定数据标识，`UiText.label()` 将标识转换成显示名称。

## 新增语言

后续为其他语言建立 `values-语言代码/`，保留相同资源键和格式占位符，只翻译值。不要翻译 SharedPreferences 键、JSON 字段、URL、机构代码、版本号或用户输入。中国行政区划名称、源站内容和设备提供的名称属于数据，不因界面语言机械改名。

本地英文内测包同步全部界面资源，并以英文作为默认资源，中文系统也可测试；稳定标识仍保留原值。未新增正式语言选择功能。运行 `tests/resource_checks.py` 检查漏引用、标识误翻译和遗漏的中文硬编码，再运行核心检查、对应语言的模型检查及 Android 界面验证。

1.2.14 的紫外线防护说明、设置默认排序和更新记录继续使用 XML；正式版保持中文，本地英文内测版同步同一组资源键及格式占位符。

1.2.15 的相机双参数、电池优化入口、精简后的说明及更新记录使用相同 XML 资源键同步英文。旧相机配置键作为室内参数保留，不翻译持久化标识。
