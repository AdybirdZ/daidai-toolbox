# 3.0.1 · 性能修复与集中设置

版本名称 3.0.1，版本代码 57；包名和签名沿用原版。当前验证及发布状态以 TESTING.md、GitHub Release 和本地 release.json 为准。

## 修复与调整

应用商店的单项和批量更新使用同一判断，包含旧接口或无法运行但仍保留的应用包。在官方备用接口成功后，短暂优先使用同一接口，避免批量下载逐包重复等待已失败的原始域名。下载进度变化和列表重绘保持可见卡片的位置；卸载结束后刷新当前界面，不强制返回桌面。地震应用卸载或更新后，未结束请求不再读取已卸载的资源或写回过期结果。

状态、地震和天文的卡顿与主线程反复检查资源包、重复计算及系统服务查询有关，未发现限制整个屏幕帧率的代码。资源缓存命中时不再检查全部应用文件；电池、内存和存储采样转至后台且不堆积任务；磁偏角复用计算。相同坐标的定位时刻变化不重建地震列表，普通排序仅更新距离，附近筛选和距离排序仍重新计算。显示目标刷新间隔保持 50 ms，实际表现取决于设备。

设置在独立设置窗口中以完整页面导航，应用内设置入口直达对应分组；返回逐层退回，修改选项留在当前页面。设备通信、音乐和色觉模拟器的设置也使用此入口。资料删除、覆盖及权限相关的必要确认继续保留。

修复设备通信消息区与外层页面争抢滚动手势的问题，阅读旧消息时更新状态或收到新消息保持阅读位置。修复窄屏课程编辑操作按钮被裁切。色觉模拟器提供实时相机开启／关闭按钮，关闭后释放相机。

## 应用兼容

稳定接口仍为 `daidai-toolbox/api-1`。3.0.0 应用包可继续在新宿主中使用；调用新增设置接口的 3.0.1 应用包要求宿主版本代码至少 57。默认应用不会因升级而重新安装已被用户卸载的项目。商店采用稳定目录入口，应用包仍按版本独立留存。
