# 地震数据调用许可核查（1.0.12，仅研究）

核查日期：2026-10-25。本版没有加入地震功能、数据请求或依赖。结论依据下列官方条款与实际参考代码；“有明确许可”指在其适用范围内遵守署名等条件可使用，不是对任何用途、任何司法辖区作零法律风险保证。公开访问、免费和非商业本身不等于取得再利用许可。

## 天气战士全部实际地震调用

核查本地参考提交 [`e75bbe601237d663bf611577e618c3354685f68f`](https://github.com/anyin233/weather-fighter-global/blob/e75bbe601237d663bf611577e618c3354685f68f/web/js/api.js#L630)，不是声称已审计其以后所有版本。`fetchCENCEarthquakes`、`fetchJMAEarthquakes`、`fetchUSGSEarthquakes`、`fetchEEWAll` 实际使用以下 **9 个 HTTP 接口**。前 8 个均以 `https://api.wolfx.jp/` 开头。代码注释还提到 WebSocket 地址，但这一实现没有建立这些 WebSocket 连接。

| 实际接口 | 内容 / 缓存 | 核查结论 |
| --- | --- | --- |
| `cenc_eqlist.json` | 中国地震台网最近 50 条地震 / 10 分钟 | Wolfx 服务可按条款免费访问，但未核实到覆盖此转发目录的 CENC 明确开放再利用许可。 |
| `jma_eqlist.json` | 日本气象厅最近 50 条地震 / 10 分钟 | JMA 官方普通内容有 PDL 1.0 / CC BY 4.0 使用依据；仍须确认 Wolfx 字段的来源、加工和第三方内容。优先直接使用官方明确许可的目录。 |
| `jma_eew.json` | 日本紧急地震速报 / 1 分钟 | 不能仅用普通网页版权许可推定预警发布业务也完全获准，另有气象业务法约束。 |
| `cenc_eew.json` | 中国地震台网速报 / 1 分钟 | 未核实到该具体产品的转发授权。应根据实际内容区分震后速报与预警，不因文件名含 `eew` 就断言所有字段都是预警。 |
| `sc_eew.json` | 四川省地震局相关速报 / 1 分钟 | 未核实到覆盖该转发链的官方授权；官网可访问不等于授权。 |
| `fj_eew.json` | 福建省地震局相关速报 / 1 分钟 | 同上；官网为动态页面，不能把未读到许可当作允许。 |
| `cq_eew.json` | 重庆市地震局相关速报 / 1 分钟 | 对实际涉及的地震预警信息，官方已有专项授权公示，且禁止获授权公司再授权其他第三方。未找到本项目或 Wolfx 在该公示中的授权依据。 |
| `cwa_eew.json` | 台湾气象署相关速报 / 1 分钟 | CWA 开放平台有明确开放条款，但尚不能把它套到这个 Wolfx 产品：未确定该接口对应的官方开放数据集及预警产品再提供条件。参考代码注释“实测可访问”不是许可。 |
| USGS `/fdsnws/event/1/query` | 直接查全球/历史地震 / 30 分钟 | 官方接口文档公开；完整当前版权页本次仍未取得可核验正文，且 ComCat 含多机构贡献，不能将整个聚合结果一概视为 USGS 自创公有领域作品。 |

USGS 查询包含时间、震级、城市坐标、半径和最多 400 条限制；默认约 700 km、近 130 天。参考项目合并 CENC、JMA、USGS 并按时间与距离去重；界面注释“全部经 Wolfx”与代码不符，以上以真实请求为准。

### Wolfx：免费服务不替代上游授权

- [官方 API 文档](https://wolfx.jp/zh/docs/open-api)。
- [官方服务条款](https://wolfx.jp/zh/legal/terms/)，第六节允许依条款和专项说明免费使用、合理缓存、正常自动化访问及公益开发；禁止绕过限流、过量请求及未获数据源条件允许的再提供。
- 第七节：“来自 JMA、CENC、USGS 或其他第三方的数据、名称、商标和内容，其权利仍归原权利人并受相应条件约束。”并“不对第三方权利或许可范围作出保证”。

因此，不能认定天气战士的全部地震调用已经取得覆盖公开 APK 再展示/转发的完整许可，也不能据此指控其一定违法。未找到许可与已证实禁止是不同结论。

### 中国官方：一般网站声明与预警授权要分别看

[中国地震局网站声明](https://www.cea.gov.cn/cea/wzgl/wzsm/index.html)写明不得进行“商业性的原版原式地转载”，不得歪曲篡改，版权归其所有。这是限制性声明；不能反向解释为已授予任何非商业自动抓取、API 转发、批量缓存、重新分发的权利，也不能替代下属各机构和具体产品条款。

[重庆市地震局授权第三方地震预警信息转发平台公示](https://www.cqdzj.gov.cn/content.php?id=137687)（2026-08-03）列明武汉地震科学仪器研究院有限公司、青岛科信安全技术有限公司，授权期 2026-07-08 至 2029-07-07。要求原文转发、以“中国地震预警网提供”为信息源标识，并明确“不得授权任何其他第三方使用”。这不是面向公众的开放许可证，不能由非商用身份代替专项授权。此公示针对预警，不据此推断所有历史地震事实都禁止使用。

[中国地震局 2026-10-12 征求意见通知](https://www.cea.gov.cn/cea/zwgk/tzgg/5856275/index.html)还涉及《地震预警信息第三方播发服务管理办法（试行）》征求意见稿，截止 2026-10-27。核查时仍在征求意见，不能当作已生效管理办法引用。

本次同时访问了[四川](https://www.scdzj.gov.cn/)、[福建](https://www.fjdzj.gov.cn/)、[中国地震台网中心](https://www.ceic.ac.cn/)官网，未取得明确覆盖上述具体 Wolfx 产品的开放授权；`news.ceic.ac.cn` 的 TLS 证书验证失败，没有绕过证书校验。后续若采用中国官方速报，应补齐实际产品和转发链的依据；预警另行核实专项授权。

### 官方证据及关键原文

1. **GEOFON**：[Legal Notice](https://geofon.gfz.de/imprint)。原文：`Parametric data (earthquake locations, depths, magnitudes etc.) generated by GEOFON are also available with CC-BY-4.0 Licence.`；波形 `licensed by the data set providers`。网站总则与 GEOFON 具体例外同时阅读。本次经 Windows 正常证书验证读取；Python 自带 CA 在该站遇到证书链问题，不据此声称无法访问。
2. **EMSC**：[Terms of Use and Disclaimers](https://www.seismicportal.eu/terms.html)、[官方 FDSN 服务文档](https://www.seismicportal.eu/fdsn-wsevent.html)。原文：`Datasets and products downloaded from our data services are provided under the Creative Commons Attribution 4.0 International (CC BY 4.0) license, which permits reuse, including commercial use, as long as there is attribution.`；同页保留对数据库整体复制的限制。
3. **GeoNet**：[数据政策](https://www.geonet.org.nz/policy)、[API 文档](https://api.geonet.org.nz/)、[地震目录 DOI](https://doi.org/10.21420/0S8P-TZ38)。DOI 对应官方目录元数据明确写 `Creative Commons Attribution 3.0 New Zealand License`，不是只凭网站页脚推断数据许可。[官方元数据 XML](https://data.gns.cri.nz/metadata/srv/api/records/5105fdeb-f314-4d6e-8e09-bf5308278e03/formatters/xml)可复核。政策要求注明 GeoNet 及 NHC、Earth Sciences NZ、LINZ、NEMA、MBIE。
4. **JMA**：[Legal Notice](https://www.jma.go.jp/jma/en/copyright.html)、[日文条款](https://www.jma.go.jp/jma/kishou/info/coment.html)、[数字厅 PDL 1.0](https://www.digital.go.jp/en/resources/open_data/public_data_license_v1.0)。JMA 明确允许以 CC BY 4.0 替代其使用条款，同时列出气象业务法第17条预测业务许可与第23条警报限制。英语 PDL 页提示日文为正式文本。
5. **CWA**：[使用规范](https://opendata.cwa.gov.tw/about/rules)、[政府开放许可](https://data.gov.tw/license)。本次读取官方页面加载的[规范内容文件](https://opendata.cwa.gov.tw/dist/js/30.5de985aa.js)，其中第二条明确允许“非專屬、不可撤回、免授權金”利用、“得再轉授權”；第三条要求显名，未显名视为自始未取得授权。官方页面是动态应用，`/about/statement` 并非实际规范路由，应使用 `/about/rules`。
6. **USGS 待补足**：[FDSN 文档](https://earthquake.usgs.gov/fdsnws/event/1/)、[ComCat](https://earthquake.usgs.gov/data/comcat/)、[贡献机构](https://earthquake.usgs.gov/data/comcat/contributor/)可读；[版权与署名页](https://www.usgs.gov/information-policies-and-instructions/copyrights-and-credits)经 Python 返回403，Windows 请求返回202但无政策正文，故不把它列为本次完整核实许可的首选。

补查 BGS 的猜测版权路径跳到扫描许可 PDF，EMSC 的旧 Disclaimer 路径404，均未作为授权依据；EMSC 改从现行 SeismicPortal 条款确认。未联系机构、注册账户或申请任何密钥。

## 给 1.1.0 的建议

普通“最近地震/历史目录”优先考虑 **GEOFON 自产地震参数或 EMSC 的限范围查询**：全球覆盖且已有明确署名许可；GeoNet/JMA/CWA 开放目录可作相应地区补充，遵守具体产品和接口条件。不要由全球目录推断中国境内小震必然完整或实时。

中国地震速报与实时预警分别核实。当前不建议直接照搬参考项目的整套 Wolfx EEW 请求作为公开 APK 功能。若授权链未补齐，继续使用官方原页入口；不要做自制“官方预警”推送。数据许可、接口配额、版权署名与预警业务限制分别满足后，再确定 1.1.0 的实际范围。
