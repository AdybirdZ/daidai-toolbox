# pre-3.0.0-3 应用宿主

本版采用“音乐”“设备通信”“色觉模拟器”的显示名称，并改进图标、音乐导入与搜索，以及商店滚动位置保留。

主界面为图标桌面。新安装默认只有天气、状态、应用商店和设置；天气与状态也可卸载。其他应用从 GitHub 商店或本地文件安装。商店和设置属于宿主，不能卸载；应用排序只调整已安装应用的位置。

## 应用与执行边界

天气、状态、天气地图、天文、地震、课程表、随机抽取、待办事项、音乐、设备通信、色觉模拟器共 11 个应用均使用签名 `.ddapp`，在工具箱内运行，不再触发 Android 独立 APK 安装。后续音乐、设备通信和色觉模拟器只维护内部应用；旧独立 APK 保留为历史下载。视频播放器仍仅本地，计算器已取消。

`modules/apps/` 为原 8 个应用入口，`modules/embedded/` 为音乐、传话、色觉模拟的完整业务与资源。`modules/build_executable.py` 独立生成各应用 DEX，排除宿主中对应的业务类。每个音乐应用包同时包含播放、曲库、歌词、剪辑、分析和页面，不拆成额外安装项。

新 3 个应用有独立资源表、页面清单及各自的私有文件目录；宿主提供 `ModulePage`、`ModuleWorker`、音乐/传话 Android 服务桥及数据校验契约。页面与服务共用同一个应用类加载器。原 8 个应用仍共享部分宿主资源、模型与设置，尚未完成全部依赖和宿主体积裁剪，卸载不等于按比例缩小宿主 APK。

ABI 为 `daidai-toolbox/pre-3.0.0-3`，不加载旧内测版执行包。升级默认应用时保留原先卸载状态；不静默重装其他应用。商店目录在 `modules/store/pre-3.0.0-3/`。

## 安装、更新与卸载

安装检查 HTTPS 下载来源、长度、SHA-256、完整包签名、与宿主一致的证书、稳定应用 ID、入口及精确 ABI；执行文件位于宿主私有目录且只读，校验后原子替换。不接受版本降级。商店有更新时显示更新入口；也可从文件安装兼容的新包。

更新或卸载前停止旧页面和对应服务，再清除旧类加载器。卸载移除程序并停止活动，保留资料；重新安装可继续使用。音乐、传话及色觉模拟的保留资料可在“设置 → 全局设置 → 内部应用资料”单独确认删除；不会删除歌曲文件夹中的音频和歌词。

所有内部应用共进程、共 Android 权限，不是对不可信插件的隔离环境；仅接受开发者签名包。宿主 Android 清单必须声明可用权限与组件，因此安装一个内部应用不能任意增加宿主未声明的系统能力。

## 后台与提醒

课程通知以开课时刻作为系统倒计时目标，不依赖应用每分钟唤醒；开课时更新为已开始，到设置时刻移除。通知正文保留明确的开课时刻和 UTC 偏移。

设备通信由用户主动连接或等待时启动前台服务，连接、套接字与加密业务在通信应用包中。切换应用、返回桌面、锁屏不主动断开；运行通知可停止连接。后台消息默认不展示正文，可在设备通信设置开启。配对码和最近 100 条消息仅保留在内存，连接结束释放 CPU/Wi-Fi 锁，不开机自动监听。

音乐使用媒体播放前台服务，离开页面继续播放。系统强制停止、断网、关闭蓝牙、设备休眠策略及厂商省电限制仍可能中断任务，不保证永久在线或通知必达。实体设备蓝牙与厂商后台策略需另行验证。

## 资料转移

新版“一键导出全部数据”生成 ZIP，包含原工具箱 JSON 配置，以及内部应用偏好、私有附属文件、引用的歌词与曲绘。不含执行包、音频、缓存、系统授权、传话内存消息或运行中任务。保留但未安装的应用资料也会备份；恢复资料不会自动安装应用或开始采样、播放、通信。文件可能含精确坐标，应自行保管。

旧工具箱导出的 JSON 仍可导入。它能恢复旧版实际导出的天气、地点、路线、课程、待办及全局配置，但不能凭空包含旧独立音乐的私有资料。导入旧 JSON 时保留新增内部应用资料；导入新版 ZIP 会确认覆盖相应资料。格式、类型、范围、路径、哈希和嵌套深度在写入前校验，写入出错回滚原资料与文件。单文件上限 16 MiB，总备份上限 256 MiB。

目录授权不能作为备份权限恢复；音乐文件夹可能需要重新选择。音乐同机迁移见 [MUSIC-MIGRATION.md](MUSIC-MIGRATION.md)。原 8 个应用的单项配置导入导出继续保留；音乐也有专用资料迁移入口。

## 构建与验证

完整工作区使用 `scripts/test.ps1`、`scripts/build.ps1`；独立源码可执行 `python tests/run.py --json-jar <json.jar>` 和 `python build.py --sdk <SDK> --out <APK>`。构建同时生成 11 个签名应用包及目录，仅天气和状态随宿主预装。不公开签名私钥，使用自有签名重建时，宿主和模块须一并重新构建。

本轮测试入口为 `tests/android/module_fixtures.py`、`InternalAppsUiTests`、`InternalMusicMigrationTests`、`ModuleHostUiTests` 和 `ModuleStoreOnlineTests`；只对隔离模拟器运行，具体结果见 [TESTING.md](../TESTING.md)。迁移测试的合成文件提供方与旧 UID 导出入口在 `tests/android/music_migration_device.py`，不会进入生产包。
