# 3.0.1 应用宿主

本文描述 3.0.1 / 57 的当前实现。3.0.0 和历史预览版记录独立保留；具体测试、发布与下载核对结果见 [TESTING.md](../TESTING.md) 及交付记录。

新安装默认只有天气、状态、应用商店和设置。天气与状态可卸载，商店和设置属于宿主固定入口。所有应用内底栏只保留“桌面”，商店从图标桌面进入。正式版普通按钮无阴影，保留清晰的按压反馈。

## 应用与代码边界

天气、课程表、状态、天气地图、天文、地震、随机抽取、待办事项、音乐、设备通信、色觉模拟器共 11 个应用均以签名 `.ddapp` 在工具箱内运行，不触发 Android 独立 APK 安装。一个应用对应完整功能；音乐播放、曲库、歌词、剪辑和分析是同一安装项内部的代码分层。

- `modules/apps/<id>/java/`：原八个应用的界面、专用设置及业务实现，含天气联网/城市目录处理、天文计算、地震来源处理、状态设备读取和通知业务等。
- `modules/embedded/<id>/`：音乐、设备通信、色觉模拟器的完整业务、独立资源表及署名；`shared/` 为其共用界面辅助代码。
- 宿主：桌面、商店、签名安装、全局设置、统一资料管理、导入导出、Android 组件桥，以及小型共用 DTO/模型和校验契约。天气与天文共用的天气资料、定位结果、课程/待办/路线资料格式等仍通过宿主共享层连接。

构建将应用实现从宿主 DEX 排除。原八个应用的资源由 `resource_partition.py` 按实际引用划分，使用 `stable-resource-ids.txt` 固定资源编号；专用资源随对应包加载，公共文字、稳定数据标识及校验所需的少量名称仍保留在宿主。城市目录随天气包分发。资源源文件集中维护不代表全部进入宿主 APK。

这使未安装应用不再占用对应下载包和大部分业务/专用资源空间，但宿主仍保留公共能力；默认天气和状态的安装包也随 APK 分发。不能宣称所有依赖均完全拆分，或承诺卸载后按 APK 比例减少空间。

## 稳定接口与资源

宿主接口为 `daidai-toolbox/api-1`，与 `3.0.0` 等显示版本独立。包描述声明稳定应用 ID、入口、接口、最低宿主版本、最低 Android 版本、配置契约及权限；只有接口相同且满足最低版本时才安装。未来普通应用更新不必随每个宿主显示版本整体重建，但新增或改变接口必须保持兼容或提高接口版本。

原八个应用挂载固定资源 ID 表；编号只能增补，不得重排或复用已分配编号。音乐等三个应用使用各自资源表。更新后使用不可变的资源代次路径，避免 Android 缓存旧资源表。页面与工作服务共用对应应用类加载器。

旧 pre-3.0.0-1 至 -3 执行包使用不同的精确内测接口，不因文件扩展名相同而与 api-1 兼容。商店目录按发布版本分开，历史目录仅供对应宿主使用。保留资料和包兼容是两项独立能力；恢复资料不会自动安装程序。

## 跨应用能力与缺失处理

天文可读取天气资料和当前地区；缺少有效天气资料时继续显示天体计算，气象观测条件标记为不可用，不虚构晴天。地震可使用共享的最近定位，也能主动进行有时限的前台定位或使用手动参考坐标；无需先打开状态应用。未获得定位时明确显示距离不可用，不能将空坐标当成零坐标。

应用设置只显示已安装应用的入口。通知、准时提醒、定位和蓝牙等系统设置入口根据已安装应用需要显示；宿主通用权限、快捷方式、电池限制及禁止休眠仍集中管理。内部应用共用宿主 UID 和 Android 权限，卸载一个应用不会自动撤销整套工具箱的系统授权。

## 桌面与快捷方式

桌面支持长按进入操作、编辑模式拖动排序、文件夹、图标尺寸、列数及文字大小；手机和平板分别保存布局。应用卸载后保留其布局身份，重新安装可恢复原文件夹归属。文件夹不嵌套，删除文件夹只将成员移回桌面。

可申请将某个内部应用固定为系统桌面快捷方式。快捷方式始终显式进入宿主，再按稳定应用 ID 打开；应用已卸载时提示重新安装，不执行失效入口。系统桌面是否支持或接受固定请求由设备决定，工具箱不把请求提交等同于成功。

## 安装、更新与故障恢复

商店提供包版本、大小、安装/可更新/不兼容状态、说明、更新内容和所需权限。下载显示字节进度及校验阶段，可取消、重试失败项和批量更新。批量任务串行处理；取消保留已完成安装并停止当前下载和后续队列。安装状态更新保留商店滚动位置。

安装检查 HTTPS 来源、长度、SHA-256、完整包签名、与宿主相同的证书、应用身份、入口和兼容接口；执行包位于宿主私有目录并只读加载，不接受版本降级。更新前停止对应页面和服务，校验后原子替换并清理旧实例。失败下载或校验不覆盖原包。

联网来源仅限 GitHub 官方 HTTPS 域名；`AdybirdZ/daidai-toolbox` 的 `main/modules/store/` Raw 连接失败时可匿名尝试一次 `api.github.com` Contents API 原始内容响应，不使用代理或令牌，取消后不重试，API 错误直接返回。

更新保留前一可执行包供启动故障恢复；新包确认成功启动后清理前包。此机制处理可识别的启动失败或未完成的启动状态，不保证回退任意硬件故障、系统强制停止或运行一段时间后才出现的所有错误。

所有内部应用共进程、共权限，签名验证建立开发者信任，并非运行不可信第三方插件的安全沙箱。内部包不能自行增加宿主 Android 清单未声明的系统组件和权限。

## 界面和草稿恢复

Android 提供原任务的 `savedInstanceState` 时，宿主恢复应用入口、滚动和支持的设置路径。界面完整快照保存在本机缓存，Bundle 只携带短令牌；缓存已清除、快照超过有效期或所属应用不可用时安全跳过。普通冷启动不重开旧草稿。

恢复范围包括支持的设置输入与选择、待办事项及其嵌套时间段、课程资料、地点、文件夹编辑，以及音乐支持的子界面、搜索选择和歌曲资料草稿。编辑对象已被删除或修改时，不用旧草稿覆盖新资料。课程自选周、颜色等已确认值可保留，尚未确认的二级选择框可回退父编辑界面。

不会重放删除/覆盖确认、系统文件选择器和权限弹窗，不自动继续导入、音频处理、测 BPM、路线记录、相机采集或设备连接。进程内正常后台播放、通信由各自前台服务负责，与任务重建恢复是不同机制。这不等同于永久自动保存所有操作。

## 统一资料管理与转移

“设置 → 全局设置 → 应用资料与存储”覆盖全部 11 个应用，包括已卸载应用保留的数据。分别显示程序、个人资料和缓存用量，并提供单应用导出/导入、确认清理缓存、确认删除资料。统计不包含宿主全部公共资源、系统运行开销及外部歌曲文件，不用于替代系统存储统计。

卸载仅移除程序并停止活动，默认保留资料。独立删除个人资料不卸载程序，也不删除授权歌曲文件夹中的音频、歌词、外部用户文件或导出文件。删除前停止对应活动；路线记录尚未结束时要求先处理记录。

完整导出为 ZIP，包含工具箱配置、11 个应用的保留资料、私有附属文件及引用歌词/曲绘；不包含执行包、音频、缓存、系统授权、通信内存消息或运行任务。未安装应用的保留资料也会备份。恢复不会自动安装应用或开始采样、播放、通信。

兼容导入旧工具箱 JSON，只恢复文件当时实际包含的内容，不凭空包含旧独立音乐数据。导入前校验格式、类型、范围、路径、哈希和嵌套深度，确认后写入，写入失败回滚。完整备份单文件上限 16 MiB，总上限 256 MiB。目录授权不能从备份恢复，音乐可能需要重新选择文件夹。正式 3.0.0 已取消旧独立音乐的专用同机迁移入口及对应 ZIP 导入导出，不再接收该辅助流程产生的迁移包。统一完整备份和单应用资料导入导出仍适用于当前内部音乐，两者不能混淆。

## 后台与提醒

课程通知以开课时刻为系统倒计时目标，不依赖应用每分钟唤醒；开课后更新为已开始，到设置时刻移除。课程及待办具体通知业务由对应应用提供，宿主保留系统服务/广播调度桥。

设备通信在用户主动连接或等待时启动前台服务，切换应用、返回桌面或锁屏不主动断开；通知可停止连接。配对码和最近消息保留在内存，不开机自动监听。音乐使用媒体播放前台服务，离开界面可继续播放。

系统强制停止、断网、关闭蓝牙、设备休眠策略及厂商省电限制仍可能中断任务，不保证永久在线或通知必达。实体蓝牙、厂商文件提供方及后台策略的验证范围见 [TESTING.md](../TESTING.md)。

## 构建与验证入口

完整工作区执行根目录 `scripts/test.ps1` 和 `scripts/build.ps1`；独立源码执行 `python tests/run.py --json-jar <json.jar>` 与 `python build.py --sdk <SDK> --out <APK>`。构建同时生成 11 个签名包及商店目录，只有天气和状态预装。公开源码不含签名私钥，使用自有签名时须同时重建宿主与应用包。

桌面、商店、资料管理、架构与状态恢复分别有设备交互测试；模型、兼容性及资料格式有核心测试。测试文件存在不代表已运行或已通过，具体设备、语言、结果和未验证项以 [TESTING.md](../TESTING.md) 为准。[后续计划](ROADMAP.md) 单独记录尚未实装内容。

## 集中设置

3.0.1 使用独立设置活动窗口，设置内容作为窗口内页面挂载并维护返回层级，不打开浮动设置窗口。各应用入口直接选择其分组，返回刷新原应用；音乐、设备通信和色觉模拟器使用宿主设置容器及自己的资源。删除与覆盖等高影响操作继续使用确认框。新增设置接口只增补 api-1，调用它的新版应用包声明最低宿主 57；旧应用包仍可加载。
