# pre-3.0.0-1 应用宿主

本版提供可执行应用安装流程。桌面显示已安装应用的图标，默认安装天气、状态；设置和应用商店为宿主固定入口。长按应用图标，或在商店对应条目中选择卸载。应用排序位于“设置 → 全局设置 → 应用排序”，没有另一套显示开关。

## 两种应用形式

| 形式 | 应用 | 安装及资料 |
| --- | --- | --- |
| 工具箱内应用 | 天气、状态、天气地图、天文、地震、课程表、随机抽取、待办事项 | 安装签名 `.ddapp`，在宿主内运行；卸载移除执行文件并停止活动，保留原偏好、地点、路线及其他个人资料 |
| 独立 Android 应用 | 呆呆音乐、呆呆传话、呆呆色觉模拟 | 商店下载现有签名 APK，交由 Android 确认安装；桌面显示启动入口，权限、文件授权与私有数据由各应用独立管理，系统卸载通常会删除其私有数据 |

计算器已取消；视频播放器仍为本地测试程序，不进入公开商店。

## 执行包与构建

工具箱内应用源码在 `modules/apps/<id>/java/`。`modules/build_executable.py` 将各入口及其内部类单独编译为 DEX，用 APK 签名格式封装为 `.ddapp`。每包具有自己的 Android 包标识、`assets/module.json`、执行代码和宿主 ABI 要求；描述文件列出权限、共享组件桥及配置分组/键规则。它不是清单 ZIP，也不是完整工具箱 APK 的复制品。该封装仅供工具箱加载，不提供独立 Android 启动 Activity。

`build.py` 明确从宿主 DEX 中排除这些应用入口及内部类。天气、状态的执行包随宿主放在 `assets/default-apps/`，仅在第一次初始化时安装。其他应用的执行包不随宿主预装。卸载默认应用后，再次进入或重建页面不会擅自重装。

宿主 ABI 为 `daidai-toolbox/pre-3.0.0-1`。当前共享层仍包含语言资源、样式、配置迁移、部分通用业务模型、部分设置实现及 Android 定位/提醒桥接。旧类中的受支持调用面公开为此内测 ABI；动态应用不可依赖宿主私有成员。同名 Java 包在不同类加载器中没有包级访问特权。

这是一版可运行的安装宿主，尚未完成每个应用全部依赖与资源的独立裁剪；卸载应用不会按比例缩小宿主 APK。今后修改共享 ABI 必须升级 ABI 并提供相应版本的应用包，不能直接加载不同宿主版本的旧执行包。

本项目使用 `python build.py --sdk <SDK> --out <APK>` 构建；完整工作区可用 `scripts/build.ps1`。不要通过常规的“将所有 Java 类合进单个 DEX”构建替代拆包步骤。源码包包含构建脚本、应用源码、资源和商店索引；不含开发者签名私钥，构建者使用自己的签名时应安装自行构建的同签名模块。

## 商店与信任边界

商店目录：`modules/store/pre-3.0.0-1/catalog.json`。客户端从仓库主分支读取目录，目录无法更新时保留随安装包提供的条目；执行包仍需联网下载，也可从文件选择器安装本版签名 `.ddapp`。

下载使用 HTTPS，并限制到 GitHub 及其资源域名；有连接/读取超时和 32 MiB 大小限制。安装依次检查下载 SHA-256、完整包签名、开发者证书、应用身份、宿主 ABI、入口和执行代码。不会将目录里声明的证书当成新的可信证书。工具箱内应用必须与宿主使用同一证书；三款独立应用使用其既有证书固定值。

执行包写入宿主私有目录，写入时即置为只读，校验通过后原子替换。校验失败保留原包，不在公共下载目录直接加载代码。内置模块与宿主共进程、共权限，并非安全沙箱；仅支持开发者签名模块。安装确认说明保留这一边界。

商店请求 Android 安装独立应用时，仅通过受限 ContentProvider 授予安装器读取暂存 APK 的权限；不静默授予“安装未知应用”权限。用户拒绝或取消后，不把发出请求当成安装成功，以系统实际包和证书状态决定是否显示入口。

## 生命周期与资料

页面切换、前后台和卸载分别处理。卸载状态会停止定位、相机/传感器、路线记录；卸载待办或课程表会取消相应提醒，不再通过开机或时间变化重新调度。共享权限不会被另一应用的卸载自动撤回。权限设置按已安装应用需要显示通知、准时提醒和定位入口；全局外观、语言、资料转移和管理能力始终存在。

完整配置导出包含未安装应用已保留的个人资料；导入配置不安装可执行文件、不恢复系统权限或启动采样。单应用配置严格限制到所属分组与键，验证后确认覆盖，写入失败回滚并重建页面模型。旧 2.1.5 配置可以继续使用。独立 Android 应用的私有曲库和 URI 授权不能通过宿主直接读取或转移。

## 验证入口

核心测试：`scripts/test.ps1`。

模块设备检查先运行 `python tests/android/module_fixtures.py`，再运行 `python tests/android/run.py --suite ModuleHostUiTests --language zh-CN`（英语为 `en`）。仅在隔离模拟器上运行；测试会安装、卸载模块，检查错误签名、损坏文件、错误 ABI、越界路径、校验失败保留原包、宿主不内嵌入口、零应用桌面与资料保留。在线商店下载和独立 APK 安装另在发布验证记录中记载。
