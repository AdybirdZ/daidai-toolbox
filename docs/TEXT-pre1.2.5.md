# pre1.2.5 文字与排版调整

本地预览版，版本名称为 `pre1.2.5`，versionCode 为 27。仅保存于本地，不推送 GitHub，不修改正式版 1.2.4 的发布文件；后续可直接覆盖同名预览产物，无需另存备份。

本次检查范围为应用内天气、天气地图、天文、状态、地震、课程表、设置、提示消息、更新记录及无障碍描述。保留数据许可、署名、来源链接、估算边界和授权待确认事项。

## 用语

| 原表述 | 调整后的表述或处理 |
| --- | --- |
| 公司排序 | 按卫星系统排序，保留原设置键与系统顺序 |
| 选中的星星信息 | 选中的天体信息，涵盖太阳、月球、恒星、行星和深空天体 |
| 高度、方位 | 天文位置统一使用高度角、方位角 |
| 月球在地平线上 | 月球在地平线上方，避免误解为正好位于地平线 |
| 以自己为中心 | 以当前位置为中心 |
| 海拔相对 WGS84 椭球、垂直误差半径 | 明确数据为 WGS84 椭球高，垂直误差采用“估计”表述 |
| 天气与地震等待提示中的口语 | 改为请求状态、失败原因及可执行的操作 |
| 天气图例中的兜底、新代码等实现描述 | 改为数据缺失、格式异常或版本尚不支持的天气代码 |
| 流星雨活跃期 | 明确极大日前后 3 天仅为应用参考显示期，不代表完整活跃期 |
| 手机当地时间（全局选项） | 改为“自动（默认）”，说明各栏目的默认时区及实际生效范围 |
| 课表的老师、默认前缀等 | 统一使用教师，并以中文引号界定前缀内容 |

中文与拉丁字母、数值、单位之间按可读性保留空格。输入范围使用“～”，界面增减时间使用统一的数值与单位格式。天气电码和既定天气名称不改变，地震复核状态仍为已复核、自动结果、状态未知。

## 段落

新增 `TextParagraphs`，用于天气图例、状态及路线说明、传感器说明、天文计算说明、缓存管理、地震术语、数据来源与隐私及 Wolfx 确认提示。

- 每段独立排版，段间距固定为 12 dp，不再随字号或空行数量改变。
- 长说明附加行间距固定为 4 dp，字体仍随系统字号缩放。
- 兼容 CRLF、LF 及连续空行，保留段内有意义的换行。
- 按钮、标题、表格行、实时卫星记录的布局仍按各自用途设置。

## 数据与行为

本次以文字和说明排版为主，不修改定位频率、传感器数据、天气解释算法、天文坐标算法、地震筛选与合并逻辑、课程表数据或保存格式。地震授权提示改用可滚动的统一段落布局，确认和取消的逻辑保持一致。天文页时间标题显示实际 UTC 偏移，避免在选择北京或 UTC 时间后仍标为当地时间。

本次没有新增在线数据源、权限或第三方依赖。既有自定义设置和已保存数据继续保留。
