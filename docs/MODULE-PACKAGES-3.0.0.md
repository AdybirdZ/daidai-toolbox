# 3.0.0 模块资产包验证记录

日期：2026-11-09。资产包面向未来的 3.0.0 宿主，源代码快照为正式工具箱 2.1.5，当前宿主仍是单体 APK。

## 范围

已生成天气、天气地图、状态、课程表、天文、地震、随机抽取、待办事项及全局设置共 9 个资产包。每个 ZIP 包含 `module.json`、`configuration-contract.json`、双语说明和 MIT 许可文件；包内声明 `standaloneInstallable: false`，要求 `daidai-toolbox/3.0.0` 宿主。

天气地图单独使用稳定模块 ID `weather-map`，并记录 `radar_region`、`map_product` 两个宿主全局配置键。

## 检查

- `python modules/build_packages.py` 成功生成 9 个 ZIP、索引和 SHA-256 清单。
- 每个 ZIP 均可读取，包含四个预期文件；索引中的文件名、大小和 SHA-256 与实际文件一致。
- `modules.json` 的稳定 ID、包路径、宿主 API 和索引一致，未包含音乐播放器等独立本地原型。
- 包内说明明确当前 2.1.5 不能安装、卸载或运行这些资产；动态下载、校验、安装、启用和卸载由 3.0.0 宿主负责，避免把单体 APK 伪装成独立模块。

## 限制

当前没有为每个栏目编译独立 APK。现有栏目代码仍共用 `MainActivity` 和宿主服务；要实现真正的独立安装，需要在 3.0.0 中提供模块 API、生命周期、权限隔离、数据迁移和卸载回滚。
