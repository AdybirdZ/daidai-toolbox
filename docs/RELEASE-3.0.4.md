# 呆呆工具箱 3.0.4

3.0.4 / versionCode 60。包名 `org.simpleweather.app`、原签名及 `daidai-toolbox/api-1` 保持不变。11 个内部应用包为 3.0.4 / versionCode 9，要求当前宿主版本代码至少为 60。

## 更新内容

- 天文星表新增 20 颗传统星名对应的恒星点，并记录 HIP 编号、位置、星等和资料来源。新增条目、对象对应关系及许可见 [星表记录](ASTRONOMY-3.0.4.md) 与 [数据 JSON](ASTRONOMY-3.0.4.json)。
- 天气地图图种选择区与浏览器链接之间增加间距。
- 音乐导入诊断中，成功项显示“已完成”。旧的最近导入报告读取时也会将成功项规范为完成状态。空歌单和空的“我喜欢的音乐”显示准确提示。
- 音乐文件夹的资料扫描缓存保存在音乐模块的本地设置中。记录文件名、MIME 类型、大小和修改时间，未变化的歌曲在宿主升级后不会重新解析。文件发生可检测变化时，只重新读取对应歌曲，并跳过用户手动编辑过的歌曲。历史版本未记录文件戳，首次升级扫描会以当前状态建立缓存，不批量重读现有曲库。
- 设备通信打开“通知设置”再返回时保留原页面及阅读位置。音乐、设备通信和色觉模拟器底部“桌面”按钮改为固定宽度，并收紧音乐标签栏与桌面按钮的间距。“播放”标签改为“当前播放”。
- 商店拒绝版本号高于已安装工具箱的内部应用包。应用商店可检查 GitHub 最新正式宿主版本，显示可用更新，用户选择下载后验证官方资产 URL、SHA-256、包名、版本及原签名，再交给 Android 系统确认安装。不会静默安装。
