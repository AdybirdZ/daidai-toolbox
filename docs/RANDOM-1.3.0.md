# 随机抽取 1.3.0

新增独立模型 `RandomChoiceModel` 与界面 `RandomChoiceScreen`，底部栏目使用新 ID 6，不改变既有 ID。默认显示，可在底部栏目设置中排序或隐藏；本轮仍在现有 app 模块内实现。

## 抽样与状态

候选支持换行、逗号、顿号及分号分隔，去首尾空白并作 Unicode NFC 规范化，完全相同的内容只保留一项。每轮用 SecureRandom 和部分 Fisher–Yates 洗牌，取前 k 项；每个有序 k 项样本有相同的分支概率，不用取模或时间种子。

每轮内部不重复，跨轮排除默认关闭；开启后跳过当前候选池的已抽项，包括此前从同一池抽中的项目。修改候选内容或顺序后，下次抽取建立新池；载入名单或重置进度立即清空结果及已抽记录。抽取数量不足时提示，不自动重置或改变用户数量。

点击后先确定并保存结果，再用同一块文字轮换、逐渐减速。可直接显示结果，关闭系统动画也会跳过展示。离开栏目或应用后台时结束动画，不再次抽取、不退还已选项，没有后台动画任务。

## 资料与兼容

`random_choice/data` 保存版本化 JSON，包含草稿、数量草稿、候选池、已抽集合、结果和命名名单。延迟写入输入草稿，生命周期边界主动保存；旧配置缺少该分组时保留当前资料。新配置完全校验后覆盖，导入期间禁止旧模型继续写入。

最多 2000 项、每项 200 个字符、候选输入 262144 个字符；最多 100 份名单，名单项总字符数不超过 400000。限制用于控制本机输入及文件规模。编辑中暂时无效的草稿仍可恢复，不影响已保存名单；完整配置拒绝异常类型、重复名单身份和不一致的抽取进度。

缓存清理和恢复设置保留随机抽取资料；恢复设置只将跨轮排除和动画选项恢复默认。删除名单需确认，载入名单使用保存时的快照。导出可能包含个人姓名等内容，由系统选择器决定保存位置；应用不上传。
