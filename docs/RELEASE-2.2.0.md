# 2.2.0 自定义桌面图标

全局设置新增“应用图标”。通过系统选择器读取图片，在方形框内拖动、缩放、裁剪，保存后可添加或更新桌面快捷方式，也可恢复默认图标。原图片不被覆盖，图标仅在本机保存。

Android 的普通应用不能将用户图片写入安装包资源，因此应用列表和系统设置仍使用默认图标。快捷方式由桌面管理，需要桌面支持，添加时可能要求用户确认；提交请求不等于已经添加。更新使用固定快捷方式 ID，恢复默认不会另外新建快捷方式。

完整配置包含自定义图片；旧文件没有该字段时保留当前图片，明确为空时清除自定义图片。导入校验字节数、解码与方形尺寸，并在写入失败时尝试回滚；导入只恢复本机图片，桌面更改仍由用户手动执行。单独的“全局模块”JSON 不含图片，应使用完整配置转移图标和背景。

测试 APK 与正式程序分目录：音乐 0.4.0、传话 0.2.0、色觉模拟 0.2.0 位于 `test-apk/`，可构建快照位于 `test-apps/`。这些是独立 Android 应用，当前工具箱不能在内部安装它们；未来 3.0.0 宿主尚未发布。视频播放器仍仅本地保存，计算器已取消。

验证与限制见 [TESTING.md](../TESTING.md)，历史变更见 [CHANGELOG.md](../CHANGELOG.md)。
