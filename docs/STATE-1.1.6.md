# 平板与页面状态恢复 · 1.1.6

1.1.5 只声明 portrait，部分平板忽略方向请求或使用兼容窗口，无法保证不重建 Activity。这也不能修复重建后从磁盘加载统一标为缓存的问题。

1.1.6 在平板（最小宽度至少 600dp）允许正常横竖屏；手机保留竖屏请求。MainActivity 接管 orientation / screenSize / smallestScreenSize / screenLayout 变化，只重新测量视口，不重建页面或地震控制器，不触发额外目录请求。系统仍可按自身策略处理多窗口或强制方向，但不再以方向锁定作为状态正确性的前提。

系统重建或回收进程后恢复任务时，通过小型 saved-instance metadata 保存当前栏目、天文时间、滚动位置、底栏窗口，以及地震逐来源的 fetched 时间戳、获取/缓存区别、失败提示和已展开条数。不在 Bundle 中塞入整个目录；目录继续使用现有磁盘缓存。只有缓存 fetched 时间戳与保存元数据精确匹配时，才恢复其“已获取”标签。缓存被替换、删除或清除时不复用旧标签；损坏元数据安全回退为本机缓存。真正冷启动没有恢复状态时仍显示本机缓存，不把缓存改名冒充联网获取。

没有新增权限或上传任何状态、坐标。参考经纬度标题明确负数为 W/S、正数为 E/N，原数值计算与存储方向不变。
