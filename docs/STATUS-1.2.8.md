# 呆呆工具箱 1.2.8

本版继续使用 Open-Meteo 天气接口和 GeoNames 地区目录。地区选择页移除预置城市按钮；中国市级离线目录保留经纬度、行政区和名称字段，搜索时将在线结果按规范化名称和约 0.12° 坐标范围去重。在线地理编码结果仍可能因来源覆盖差异缺少某些地区，应用会保留离线目录用于检索。

新增路线改名与排序、全局配置 JSON 导出、天文旋转矢量对准天空，以及环境光系统传感器/相机来源选择。相机功能仅在用户明确启动并授予相机权限后工作，图像亮度样本不是经过标定的照度值。

英文资源只进入本地 pre2.0.0-1 预览包，正式中文源码和 GitHub Release 不包含 `values-en`。
