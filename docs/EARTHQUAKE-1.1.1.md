# 1.1.1：Wolfx 转发的 CENC 近期目录

日期：2026-10-26。适用于免费、个人非商业工具箱的近期震后信息展示，不含预警。

## 已接入与限制

- 客户端直连 `https://api.wolfx.jp/cenc_eqlist.json`，仅此目录；不连接 `cenc_eew`、WebSocket 或任何预警流。
- 来源显示为“CENC（Wolfx 转发）”。Wolfx 是非官方服务，数据仅供参考，不能替代官方渠道。
- 按文档，接口提供最新最多约 50 条，按发布顺序；不是按所选天数完整查询的历史数据库。状态区显示本次条数和最早发生时刻。短时间内事件多时，较早事件可能被挤出；筛选后为空不表示没有发生地震，不保证中、大地震一定收录或固定延迟。
- 按 UTC+8 解析 `time`（发生时刻）和 `ReportTime`（来源报告时刻），再按用户时区显示。事件 ID 不用于推算发生时刻。优先保留原始 `placeName`，缺失才使用加工后的 `location`。
- 震级类型不明时仅显示 M，不擅自称为 Mw 或中国震级。缺失深度不当作 0 km；未采用含义、计算模型与标度尚未核实的 `intensity` 字段，不将其当成正式最大烈度，也不转换为中国地震烈度或 MMI。
- 跨来源同时满足时间差不超过 20 秒、震中距离不超过 35 km、震级差不超过 1，且各来源间双向最近匹配无明显歧义才合并。三来源要求两两匹配，避免链式合并密集余震；保留每份参数，不取平均。
- 默认三个来源开启，设置中可单独关闭，至少保留一个。升级保留既有 GEOFON / EMSC 开关和其他设置，未保存的新 Wolfx 开关默认开启。
- 默认仅地震页前台每 15 分钟自动刷新，关闭自动刷新时空缓存也不会自动请求；手动请求至少间隔一分钟，遵守限流与 Retry-After。切换天数或震级仅本地过滤 Wolfx 已取目录，不把 50 条缓存误称为覆盖完整范围。
- 独立持久缓存，断网或失败保留上次成功结果；清除地震缓存同时清除三个来源，旧在途结果不回写。关闭来源后不发新请求、不在合并列表使用该来源，保留其已有缓存供再次开启使用。

## 隐私与验证边界

请求 Wolfx 会向其服务发送网络请求及 IP、应用 User-Agent；不发送参考经纬度、定位精度、课程、背景、收藏等。地表距离、区域/时间/震级筛选都在本地进行。本版不新增权限、依赖、后台目录任务或地震通知。

单元测试使用合成 Wolfx 数据，未将实取的完整 CENC 目录打包为公开夹具。真实获取只用于本机验证。缺乏可靠最大烈度资料及适用估算模型时，仍显示暂无可靠结果；本版不承诺实测官方烈度或估算烈度。
