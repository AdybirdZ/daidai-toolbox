### 本版遵守的调用条件

- 基础天气与地区检索仅调用 `https://api.open-meteo.com/v1/forecast` 和 `https://geocoding-api.open-meteo.com/v1/search`。没有私有接口、抓取代理、来源请求头伪装或切换主机规避限流。

- 429 响应遵守数字或 HTTP 日期形式的 `Retry-After`，至少暂停一分钟；没有该字段或解析失败时也暂停一分钟。保留失败提示，不通过备用域名绕过限制。
