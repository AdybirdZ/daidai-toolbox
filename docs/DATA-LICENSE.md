### 本版遵守的调用条件

- 基础天气与地区检索仅调用 `https://api.open-meteo.com/v1/forecast` 和 `https://geocoding-api.open-meteo.com/v1/search`。没有私有接口、抓取代理、来源请求头伪装或切换主机规避限流。
- 条款规定免费额度低于每天 10,000、每小时 5,000、每分钟 600 次。服务商对多变量查询可能折算为多次调用。本版每安装限制为每分钟 20、每小时 1,000、每天 2,000 次 HTTP 请求；当前天气查询的变量数在 30 以内，按每次不超过 3 个计费调用保守控制。配额及 429 冷却状态保存在本机，重启应用不清零。服务商按 IP 等方式实际计算的额度仍以其响应为准，同一网络其他使用者也可能影响可用额度。
- 天气缓存 15 分钟，手动刷新同一地区间隔至少一分钟；合并同一地区正在进行的请求。地区查询只在点击“搜索”时联网。没有后台轮询。
- 429 响应遵守数字或 HTTP 日期形式的 `Retry-After`，至少暂停一分钟；没有该字段或解析失败时也暂停一分钟。保留失败提示，不通过备用域名绕过限制。
- 天气数值作中文描述、取整和排版；内置地区个别名称、行政标签和时区经过整理。应用内已说明数据展示处理。中国地区使用北京时间，其他地区使用服务返回的当地时区。
- 当前天气标注为“模型估算”，没有标成中国气象局台站实测，也不冒充官方预警。

商业化、接入广告、订阅或扩大运营规模前，应重新核查条款并取得对应 API 服务授权。此次核查针对所选数据和调用用途，不等于对未来上架、运营、商标、备案等事项作全面法律审查。

## 安装与使用

1. 安装 `DaidaiToolbox-1.0.2.apk`，Android 8.0+。首次天气城市默认北京。
2. 包名 `org.simpleweather.app`，versionCode4，与1.0.1同签名，覆盖安装保留地区、收藏、旧课表、背景。早期简天气归档为 `0.1.0-test`，不要降级覆盖。
3. 默认底栏为天气、课程表、定位。设置→底部栏目可开启天气地图、天文，以及调整所有栏目的显示和顺序。只有一个栏目时隐藏底栏，五个时用左右箭头切换可见按钮，禁止手指横滑底栏。
4. 设置→天气可调整地区、当前天气、24小时、7天、详情及来源入口的显隐和排序，也可查看完整图例。必要数据署名跟随内容保留。
5. 天气地图有五个常驻图种按钮：一个默认区域雷达入口、日降水量、降水预报、逐时气温、卫星云图；设置→天气地图可选默认雷达地区。
6. 课表设置可调整学期和上下课时分，新增课程含名称、地点、老师、节次与授课周；可选每周、单周、双周或多选任意自定义周，例如1、3、4、6周。信息前缀独立可配置。点击课程可编辑删除，冲突会提示。
7. 设置→背景可选图并拖动/缩放选区、调背景亮度和恢复默认；设置→描边可开关并选择颜色，默认开启黑色描边。
8. 设置→关于集中版本更新与数据隐私。更新含1.0.2、1.0.1、1.0.0与0.1.0-test，首次升级展示。

接口可用性与国内网络质量以手机实际环境为准。失败时提示错误，有历史天气时明确标记；不会生成假天气。
