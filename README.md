# 呆呆工具箱 3.0.0

面向个人、非商业使用的免费开源 Android 工具箱，支持简体中文与英语。主界面采用图标桌面，默认安装天气和状态；设置与应用商店是固定入口。其他应用可从 GitHub 商店下载，也可从文件安装受信任的签名应用包。

当前为正式 3.0.0（versionCode 56）待发布版本。本地核心、中英文设备验证和公开源码独立重建已通过，GitHub 在线安装及发布记录尚待核对。pre-3.0.0-4 / 55 的本地构建与验证独立保留。当前状态见 [验证记录](TESTING.md)，实际下载以 GitHub Releases 为准。

## 可安装的应用

- **天气**：地区搜索与收藏、当前天气、逐小时及逐日预报。
- **天气地图**：在中央气象台官方页面查看降水、雷达、气温、卫星云图及天气图。
- **天文**：近似星图、设备指向、日月行星、月相与流星雨参考。
- **状态**：指南针、定位、卫星、传感器、电池、设备信息、地点与路线记录、回放。
- **课程表**：学期、周次、课程信息及每日课程提示。
- **地震**：近期目录、参考位置距离及 MMI 烈度估算，不作预警。
- **随机抽取**：自定义名单、抽取数量、排除已选项及可选动画。
- **待办事项**：指定时段、全天、多天或待安排事项，支持重复、子任务、提醒与常驻摘要。
- **音乐**：本地曲库、歌单、歌词、曲绘、剪辑、BPM、后台播放及音频分析。
- **设备通信**：蓝牙或局域网点对点加密文字通信，活动连接可在后台继续。
- **色觉模拟器**：图片和相机的红、绿、蓝色觉缺陷近似模拟及分屏对照。

11 个应用均在工具箱内运行，天气和状态也可卸载。每个应用是一个完整安装项，音乐的歌词、剪辑和分析无需分别安装。原有八个应用的业务代码、专用设置和大部分专用资源已进一步分包；小型共用模型、资料校验契约和 Android 组件桥仍由宿主提供，不能将卸载理解为按比例缩小宿主 APK。

## 桌面、商店与资料

桌面支持拖动排序、文件夹、图标尺寸、列数和文字大小，手机与平板分别保存布局。正式版普通按钮统一取消阴影并保留按压反馈。长按应用可申请添加系统桌面快捷方式。应用内底栏只保留“桌面”；应用商店从桌面进入。

商店显示版本、包大小、安装状态、更新内容和所需权限，支持下载进度、取消、失败重试及批量更新。安装检查完整包签名、开发者证书、应用身份、宿主接口、Android 最低版本及下载校验值。接口 `daidai-toolbox/api-1` 与宿主显示版本分离，在接口兼容且满足最低宿主版本时可独立更新应用。旧内测包使用不同接口，需下载兼容包。

商店通过 GitHub 官方 HTTPS 地址联网；本仓库 `main/modules/store/` 的 Raw 连接失败时，最多尝试一次匿名 GitHub Contents API 原始内容下载，仍校验包哈希与签名。

“设置 → 全局设置 → 应用资料与存储”统一管理全部 11 个应用，显示程序、个人资料及缓存用量，支持单应用导入、导出、清理缓存和确认删除个人资料；未安装应用保留的资料也可管理。卸载应用默认保留资料，删除资料不会删除外部歌曲文件夹中的音频、歌词或用户导出文件。存储统计为应用管理范围内的文件和配置大小，不代表系统设置显示的全部安装占用。

完整备份为 ZIP，兼容导入旧工具箱 JSON。包含配置、内部应用资料及引用的歌词和曲绘，不含音频、程序、缓存、系统授权或运行任务；恢复资料不自动安装应用或开始采集、播放和连接。导入前校验并确认覆盖，导出文件可能包含精确坐标，应自行保管。正式 3.0.0 不提供从旧独立音乐导入资料的专用迁移功能；当前内部音乐仍参与统一资料备份与恢复。

Android 恢复被系统重建的任务时，可恢复支持的设置路径和编辑草稿；普通冷启动不重开过期界面或恢复设备操作。支持范围与缓存失效时的处理见 [宿主说明](docs/MODULE-HOST.md)。

## 自定义图标

在“设置 → 全局设置 → 应用图标”选择图片，裁剪后创建或更新系统桌面快捷方式，也可恢复默认图标。Android 不允许普通应用以用户图片替换安装包资源，因此应用列表和系统设置仍显示原图标。快捷方式需要桌面支持，添加时可能要求确认；提交请求不等于已添加成功。系统入口位于“全局设置 → 权限与系统限制 → 桌面快捷方式设置”，不同设备是否提供单独权限及其位置可能不同。

## 数据与隐私

天气由 Open-Meteo 提供，免费 API 限非商业使用，当前天气为模型结果。天气地图保留官方原页。天文、传感器和相机亮度仅供参考，相机样本不是照度测量。

用户资料保存在本机，无账号、广告、统计 SDK 或自建服务器。工具箱不将定位、路线、待办事项、随机名单或相机画面上传至开发者服务器；用户主动进行的设备通信及外部服务请求按对应功能工作。服务方可能接收的信息及地震来源许可边界见 [数据许可](docs/DATA-LICENSE.md)、[署名](NOTICE.md) 和应用内“数据来源与隐私”。

通知横幅、锁屏显示、常驻保留及后台运行受系统设置和厂商限制影响。全局“权限与系统限制”根据已安装应用显示相关入口；卸载内部应用不等于撤销宿主已有 Android 权限。重要提醒可另设系统闹钟，详见 [待办说明](docs/TODO.md)。

## 构建与验证

在完整本地工作区的 `source/` 目录执行：

```powershell
..\scripts\test.ps1
..\scripts\build.ps1
```

独立源码包可用 `python tests/run.py --json-jar <json.jar>` 和 `python build.py --sdk <Android-SDK> --out <输出.apk>`。构建同时生成宿主及 11 个签名内部应用包，默认仅天气和状态随宿主分发。签名私钥、SDK 与缓存不公开；覆盖升级必须沿用原签名，使用自己的证书构建时需同时重建宿主与应用包。
