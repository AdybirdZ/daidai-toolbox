# 呆呆工具箱 2.1.0

面向个人、非商业使用的 Android 工具箱。支持简体中文与英语，可在全局设置中切换语言或跟随系统。

## 功能

- **天气**：地区搜索与收藏、当前天气、逐小时及逐日预报。
- **天气地图**：在中央气象台官方页面查看降水、雷达、气温、卫星云图及天气图。
- **天文**：本地近似星图、设备指向、日月行星、月相与流星雨参考。
- **状态**：指南针、定位、卫星、传感器、电池、设备信息、地点及路线记录和回放。相机环境光支持室内、室外双参数采样及暂停。
- **课程表**：手动管理学期、周次、课程、地点、教师及上课时间。
- **地震**：近期目录、参考位置距离及 MMI 烈度估算。
- **随机抽取**：自定义名单、抽取数量、排除已选项及可选动画。
- **待办事项**：指定时段、全天/多天、重复、子任务、筛选，以及提醒和常驻摘要。

## 2.1.0 变更

- 新增待办事项，支持同一天多个时段、全天与连续多天、重复规则、分类颜色、优先级、置顶及子任务。
- 提供搜索、状态/分类筛选、三种排序，以及新事项默认值和显示设置。
- 支持开始/结束提醒、提前提醒、通知快捷完成和延后 10 分钟；可选静默常驻摘要、内容隐藏和摘要范围。
- 待办纳入完整配置导入导出；旧文件缺少待办分组时保留现有事项。清除缓存、恢复默认设置保留事项。

通知横幅、声音、锁屏显示和常驻保留受系统设置影响。请在全局设置的“权限与系统限制”检查通知和准时提醒；没有准时提醒权限时可能延迟。强制停止应用或厂商后台限制可能阻止提醒，重要事项请另设系统闹钟。详见 [待办说明](docs/TODO.md)。

## 数据与隐私

天气由 Open-Meteo 提供，免费 API 仅限非商业使用；当前天气为模型估算。天气地图保留官方原页，不转发受限图片。天文、传感器及相机亮度仅供参考；相机样本不是照度测量。

用户资料保存在本机，应用不上传定位、路线、待办事项、随机抽取名单或相机画面，无账号、广告、统计 SDK 或自建服务器。网络服务及系统定位可能接收的信息、各地震来源许可和 Wolfx 授权尚未确认的边界，见 [数据许可](docs/DATA-LICENSE.md)、[署名](NOTICE.md) 及应用内“数据来源与隐私”。

## 构建与测试

在完整本地工作区的 `source/` 目录执行：

```powershell
..\scripts\test.ps1
..\scripts\build.ps1
```

独立源码包可用 `python tests/run.py --json-jar <json.jar>` 和 `python build.py --sdk <Android-SDK> --out <输出.apk>`。签名私钥、SDK 与缓存不包含在源码包中；升级已有安装须使用原签名。
