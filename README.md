# 呆呆工具箱 2.2.1

面向个人、非商业使用的免费开源 Android 工具箱，支持简体中文与英语。语言、栏目、配色和权限入口集中在设置中管理。

## 功能

- **天气**：地区搜索与收藏、当前天气、逐小时及逐日预报。
- **天气地图**：在中央气象台官方页面查看降水、雷达、气温、卫星云图及天气图。
- **天文**：近似星图、设备指向、日月行星、月相与流星雨参考。
- **状态**：指南针、定位、卫星、传感器、电池、设备信息、地点与路线记录、回放。
- **课程表**：学期、周次、课程信息及每日课程提示。
- **地震**：近期目录、参考位置距离及 MMI 烈度估算，不作预警。
- **随机抽取**：自定义名单、抽取数量、排除已选项及可选动画。
- **待办事项**：指定时段、全天、多天或待安排事项，支持重复、子任务、提醒与常驻摘要。

各模块支持配置导入导出，完整配置可一并转移。导入前会校验并确认覆盖；权限、缓存和正在运行的任务不随文件恢复。导出文件可能包含精确坐标，请自行保管。

## 自定义图标

在“设置 → 全局设置 → 应用图标”选择图片，裁剪后创建或更新桌面快捷方式，也可恢复默认图标。Android 不允许普通应用以用户图片替换安装包资源，因此应用列表和系统设置仍显示原图标。快捷方式需要桌面支持，添加时可能要求确认。相关系统入口位于“全局设置 → 权限与系统限制 → 桌面快捷方式设置”；不同设备是否提供单独权限及其位置可能不同。

## 数据与隐私

天气由 Open-Meteo 提供，免费 API 限非商业使用，当前天气为模型结果。天气地图保留官方原页。天文、传感器和相机亮度仅供参考，相机样本不是照度测量。

用户资料保存在本机，应用不上传定位、路线、待办事项、随机名单或相机画面，无账号、广告、统计 SDK 或自建服务器。服务方可能接收的信息及地震来源许可边界见 [数据许可](docs/DATA-LICENSE.md)、[署名](NOTICE.md) 和应用内“数据来源与隐私”。

通知横幅、锁屏显示、常驻保留及后台定位受系统设置和厂商限制影响。请在全局设置的“权限与系统限制”检查相应选项，重要提醒可另设系统闹钟。详见 [待办说明](docs/TODO.md)。

## 构建与验证

在完整本地工作区的 `source/` 目录执行：

```powershell
..\scripts\test.ps1
..\scripts\build.ps1
```

独立源码包可用 `python tests/run.py --json-jar <json.jar>` 和 `python build.py --sdk <Android-SDK> --out <输出.apk>`。签名私钥、SDK 与缓存不公开；覆盖升级已有安装必须沿用原签名。主程序源码包不包含测试 APK，测试程序独立构建。
