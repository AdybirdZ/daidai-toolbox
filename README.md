# 呆呆工具箱 2.0.0

面向个人、非商业使用的 Android 工具箱。支持简体中文与英语，可在全局设置中切换语言或跟随系统。

## 功能

- **天气**：地区搜索与收藏、当前天气、逐小时及逐日预报。
- **天气地图**：在中央气象台官方页面查看降水、雷达、气温、卫星云图及天气图。
- **天文**：本地近似星图、设备指向、日月行星、月相与流星雨参考。
- **状态**：指南针、定位、卫星、传感器、电池、设备信息、地点及路线记录和回放。相机环境光支持室内、室外双参数采样及暂停。
- **课程表**：手动管理学期、周次、课程、地点、教师及上课时间。
- **地震**：近期目录、参考位置距离及 MMI 烈度估算。
- **随机抽取**：自定义名单、抽取数量、排除已选项及可选动画。

## 2.0.0 变更

- 正式加入英语，界面、历史更新记录、提示和图表标签使用中英文 XML 资源。
- 全局设置新增语言选择，支持跟随系统（默认）、简体中文和 English；切换后立即生效，保留当前栏目和已有资料。
- 语言选择随全部配置导入导出；用户输入、地名和外部网站内容保留原文。

## 数据与隐私

天气由 Open-Meteo 提供，免费 API 仅限非商业使用；当前天气为模型估算。天气地图保留官方原页，不转发受限图片。天文、传感器及相机亮度仅供参考；相机样本不是照度测量。

用户资料保存在本机，应用不上传定位、路线、随机抽取名单或相机画面，无账号、广告、统计 SDK 或自建服务器。网络服务及系统定位可能接收的信息、各地震来源许可和 Wolfx 授权尚未确认的边界，见 [数据许可](docs/DATA-LICENSE.md)、[署名](NOTICE.md) 及应用内“数据来源与隐私”。

## 构建与测试

在完整本地工作区的 `source/` 目录执行：

```powershell
..\scripts\test.ps1
..\scripts\build.ps1
```

独立源码包可用 `python tests/run.py --json-jar <json.jar>` 和 `python build.py --sdk <Android-SDK> --out <输出.apk>`。签名私钥、SDK 与缓存不包含在源码包中；升级已有安装须使用原签名。
