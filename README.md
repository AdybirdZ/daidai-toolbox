# 呆呆工具箱 1.1.0

原生 Android 个人非商业工具箱，Android 8.0+，Java，无第三方运行时依赖。页脚：呆呆鸟使用 Codex 制作。

- 天气：地区搜索、45 个常用地区、收藏、当前模型估算、24 小时与 7 日预报、15 分钟缓存及失败回退。
- 官方天气图：全国日降水量、降水预报、气温、全国及七个区域雷达、FY4B 卫星云图及天气图，通过应用内完整官方网页查看，保留原站版权、图例、发布时间，不下载重发图片。
- 天文：地平/赤道/隐藏坐标网格、旋转十字与持续选中、行星独立显隐、昴星团/仙女座星系大致中心、观星天气条件、亮星与行星示意、星点方位/高度/星等、亮星显示设置（北斗七星固定显示）、日月位置、月相、升落与曙暮光、流星雨活跃期参考与星图辐射点、指定年月日时分与前后15分钟/一天调整。本地天文计算为近似结果。
- 地震：GEOFON＋EMSC 近期双源目录，离线缓存、来源参数保留、本地距离、时间/区域/震级筛选与设置。Wolfx 上游依据待确认，未启用；无预警流。无可靠烈度资料时不生成数值，详见 [地震说明](docs/EARTHQUAKE-1.1.0.md)。
- 课程表：手动新增、修改、删除，课程名、地点、老师，学期、周次、单双周及任意自定义周、自定义上下课时间、周课表与今日课程。支持冲突检查，不含教务导入或桌面小组件。
- 定位：可选 GPS 硬件或系统网络定位，前台读取 WGS84 经纬度、水平精度及可用海拔，默认切页或后台停止更新；可主动开启持续定位前台服务，提供通知和停止按钮，应用不上传坐标。网络模式需要设备支持系统网络位置服务及联网。结果年龄逐秒更新；自动定位最短请求间隔可选1秒至10分钟，系统可能延迟或提供缓存。
- 图片背景支持拖动、缩放和选区确认，背景亮度向右增加图片可见程度；可选颜色描边、课程信息前缀、分级设置及每版本折叠的更新记录（重新进入默认全部收起）。设置逐级返回，选择保持当前页；支持一键恢复默认设置（保留课程、收藏及缓存，超出默认范围的课程保留必要周次/节次）。
- 天气与天文栏目均可显隐排序。底部栏目可显隐排序：天气、课程表、定位、地震默认显示，天气地图及天文默认隐藏；仅一个栏目时隐藏底栏，五个及以上时箭头翻页，不响应手指横滑。

首次启动定位才申请所需的前台位置权限。网络模式的系统位置服务可能向其服务商发送 IP、基站或 Wi-Fi 信息，适用系统规则。图片使用系统文件选择器，无存储读取权限。课程、背景、收藏和缓存保存在手机内部，无账号、广告、统计 SDK 或自建服务器。官方网页适用各自隐私规则。天气查询向 Open-Meteo 发送所选城市坐标，GPS 不自动更改天气城市。

天气图例包含29种已核查的 Open-Meteo 代码与未知数据提示，按白天、夜间及最右侧代码排列；代码和模型限制见 `docs/WEATHER-CODES.md`，图例底部可打开 Open-Meteo 与 WMO 官方原文；雷暴组按 WMO 原文命名，完整差异核对见 `docs/WEATHER-CODE-COMPARISON.md`。

授权与隐私见 `docs/DATA-LICENSE.md`，版本内容见 `CHANGELOG.md`，验证见 `TESTING.md`。新写客户端代码为 MIT，数据许可单独保留。

默认配置：描边关闭，颜色黑色，17 周、12 节苏州大学课程时间，三种课程前缀均显示，定位间隔 5 秒；完整时间及默认选项见 [默认设置](docs/DEFAULTS.md)。隐私页列出两个参考开源项目，最下面链接本应用仓库。

本版星图为正方形，太阳/月球可选中，标签仅在点的上下固定位置避让。独立月球信息包含本地月相图与近似月龄；月球视星等为离线经验式估算，详见 [计算与来源](docs/ASTRONOMY-1.0.10.md)。天气地图新增中央气象台“天气图”完整原页。

## 安装与升级

安装 `DaidaiToolbox-1.1.0.apk`。包名保持 `org.simpleweather.app`，versionCode 从 14 增至 15，沿用原开发签名，可覆盖1.0.12并保留地区、收藏、旧课表及背景。更早的“简天气”测试包原标 1.0.0，现统一归为 `0.1.0-test` 测试版；重新归档的测试 APK 已修正版本及名称。

使用本机开发签名，适合个人侧载。保存签名私钥才能继续覆盖升级；源码压缩包不含私钥，重新构建生成的不同密钥不能覆盖本次 APK。不是已提交商店的发行包。

## 构建

JDK 17+、Python 3、Google Android SDK `platforms;android-35` 和 `build-tools;35.0.0`：

```powershell
python build.py --sdk C:/Android/Sdk --out build/DaidaiToolbox-1.1.0.apk
```

脚本执行 aapt2、javac、D8、zipalign、apksigner。首次创建 `.signing/development.jks`，开发密码为 `android`，勿公开私钥。Windows 含中文路径已验证。macOS/Linux 需对应平台 SDK，未实测。Android Studio 可打开 Gradle 配置（AGP 8.7.3 / Gradle 8.9，未附 wrapper），本次只验证脚本构建。
