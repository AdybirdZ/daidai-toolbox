# 呆呆工具箱 1.2.11

1.2.11 是中文正式版，面向个人、非商业使用。英文资源只用于本地 `pre2.0.0-1` 内测包，未上传 GitHub。

## 功能

- **天气**：地区搜索、收藏、当前天气、逐小时和逐日预报。天气数据来自 Open-Meteo，地区目录包含中国大陆、香港、澳门、台湾及海外检索结果。
- **天气地图**：通过中央气象台官方网页查看降水、气温、雷达、卫星云图和天气图，不下载或转发受限图片。
- **天文**：本地近似计算的星图、日月行星、月相、曙暮光和流星雨参考。星图支持选择天体、地平/赤道坐标和按设备旋转矢量对准；对准时红色实体十字在固定星图上标示设备指向，仅适用于地平坐标和无网格模式，可在设置中选择外置相机方向或手机上沿方向。
- **状态**：指南针、定位、卫星状态、传感器、电池、设备信息、地点和路线绘制。环境光可使用系统传感器或相机亮度样本；相机读取不显示预览窗口，默认不在切换栏目、锁屏或后台继续工作。
- **课程表**：手动设置学期、周次、课程、地点、教师和上课时间，不连接教务系统。
- **地震**：近期目录与本机距离、MMI 估算，来源及适用边界见 `docs/DATA-LICENSE.md`。

## 1.2.11 变更

- 文字与按钮颜色改为统一选择，提供七种预设及十六进制自定义。自动生成深色文字和浅色按钮，深色按钮固定白字。
- 课程颜色支持七种预设及自定义；旧课程保留对应颜色，无法识别的颜色回退蓝色。
- 恢复默认设置、底部栏目和缓存管理归入全局设置。
- 对准天空使用设备三维朝向，固定星图上的小型红十字表示方位角与高度角；说明集中至星图下方。
- 地区条目显示经度、纬度及方向，便于核对搜索结果。小数位数不代表测绘精度。
- 相机亮度优先使用手动曝光，不支持时尝试锁定自动曝光，并显示实际状态；相机读数仍为相对亮度，不是照度。

## 数据与隐私

天气查询需要联网；Open-Meteo 免费 API 仅限非商业使用。天气地图在应用内打开中央气象台官方页面，访问数据按原站规则处理。课程、背景、收藏、地点、路线和配置保存在本机；应用不上传定位坐标。应用没有账号、广告、统计 SDK 或自建服务器。

数据许可和参考项目见 `docs/DATA-LICENSE.md`、`NOTICE.md`。新数据源必须在文档中写明来源、许可和限制。

## 构建与测试

```powershell
..\scripts\test.ps1
..\scripts\build.ps1
```

上述命令在完整本地工作区的 `source/` 目录执行；独立源码包可用 `python tests/run.py --json-jar <json.jar>` 和 `python build.py --sdk <Android-SDK> --out <输出.apk>`。

构建使用工作区 `tools/android-sdk` 和本地开发签名；签名私钥、SDK、缓存不进入公开源码包。正式 APK、源码包、更新说明和校验文件位于 `releases/1.2.11/`，GitHub 项目为 [AdybirdZ/daidai-toolbox](https://github.com/AdybirdZ/daidai-toolbox)。
