# 原型隐私与许可说明

## 数据和依赖

三个小程序的运行时仅使用 Android / Java 系统 API，没有接入天气、地震、音乐曲库或其他第三方数据服务，没有广告、遥测或分析 SDK，没有新增第三方运行时依赖。Android SDK/JDK 仅作为本地构建工具，不包含到源码交付包中。色觉模拟使用的公开模型与许可另列如下。

## 呆呆音乐

通过系统 SAF 文件选择器取得用户选取的音频及歌曲存储文件夹的访问授权。曲库在本机保存歌曲地址、名称、创作与演唱资料、备注、标签、BPM、评分、歌词、曲绘，以及收藏、歌单和播放设置。导入必须向已授权文件夹写入音频副本；文件已在该目录时不重复复制。“我的歌曲”可在确认后删除目录内所选文件，并清理其曲库、播放列表、歌单及喜欢记录。移除或清空播放列表保留曲库、附件和访问授权，不删除文件。没有 INTERNET 权限，不扫描未授权目录、不上传音频。

剪辑与音频分析使用 Android MediaExtractor / MediaCodec 在本机解码，私有缓存中暂存 PCM WAV；音频分析读取源音频左右声道，不采集麦克风或其他应用音频，不申请录音权限。剪辑仅在用户选择导出位置后写入目标文件，可选择加入倍速与音调效果。取消、失败、完成导出或关闭音频分析时清理临时文件；意外退出遗留缓存在关闭或下次打开时清理。分析和剪辑只读取原音频；删除文件须另行确认。音量滑块和上限只设置本应用播放器音量，不改系统音量；不保证其他应用或系统不会发声。

文件选择器内第三方云盘由其自身控制联网行为，建议选择本机文件。音频文件的版权和使用范围由用户自行确保；本程序不提供下载、传播或破解音乐的功能。

后台媒体播放使用 Android 的前台媒体服务，附通知/媒体会话控制；播放时使用局部唤醒锁以避免休眠中断，释放播放器时由系统释放。通知权限请求只用于显示和控制播放，不影响媒体播放权限的法定范围。

## 呆呆传话

支持经典蓝牙 RFCOMM 与本机私有 IPv4 局域网 TCP。蓝牙直接使用 Android 系统 API，不接入第三方平台或数据源。Android 的 INTERNET 权限用于局域网 Socket，不表示接入云服务器。应用校验局域网目的地址，拒绝域名和公网 IPv4；不做局域网扫描或广播发现。

蓝牙只列出系统已经配对的设备，不在程序内进行设备扫描或请求可发现模式。Android 12 及以上按需申请 BLUETOOTH_CONNECT（系统显示“附近的设备”权限），不申请 BLUETOOTH_SCAN、BLUETOOTH_ADVERTISE 或定位权限。旧版系统使用 maxSdkVersion=30 的传统蓝牙权限。系统配对本身由系统蓝牙设置完成；当前选择的蓝牙设备名称与地址只在内存中。

配对码和聊天内容仅在当前内存中。应用退出/重建不保留聊天；只保存上次输入的局域网地址及通信方式，方便再次使用。配对码不会写入偏好文件或日志；复制时将剪贴板内容标记为敏感（Android 13+），但用户和拥有剪贴板访问权的软件仍可能读取。接收方必须主动启动监听。切后台、打开系统设置或切换方式自动断开，无后台监听服务。

消息使用系统加密 API；协议参数与边界见技术说明。加密不等于身份实名验证，配对码的接收者即有会话访问权。尚未进行独立安全审计，不用于高敏感通信。

## 呆呆色觉模拟

没有 INTERNET、录音或全盘读取权限。仅在用户开启实时相机时请求 CAMERA 权限；Camera2 画面直接传到本机 OpenGL 着色器，不录制或保存，离开应用即关闭相机。多视图共用一个相机输出。图片通过 SAF 选择，在内存中处理，用户主动导出 PNG 对照拼图时才写文件，不覆盖输入文件；只在本地保存勾选的视图组合。云盘提供方可自行联网。

模型为 Machado、Oliveira、Fernandes，*A Physiologically-based Model for Simulation of Color Vision Deficiency*，IEEE TVCG 15(6), 2009，DOI [10.1109/TVCG.2009.113](https://doi.org/10.1109/TVCG.2009.113)。使用严重程度为 1 的三组 3×3 线性 sRGB 变换矩阵；数据参考 [DaltonLens-Python](https://github.com/DaltonLens/DaltonLens-Python/blob/master/daltonlens/simulate.py) 中 `machado_2009_matrices`，其 [MIT 许可](https://github.com/DaltonLens/DaltonLens-Python/blob/master/LICENSE) 已于 2026-10-31 核对并保留在 `modules/colorvision/assets/licenses/DaltonLens-MIT.txt`，同时打入 APK。没有复制论文图像或收费诊断素材，也未引入 Python 运行时。此近似模型不代表个人实际视觉，不能用于诊断。

## 发布范围

音乐、传话和色觉模拟以独立测试应用发布，APK 位于工具箱仓库的 `test-apk/`，必要可构建源码位于 `test-apps/`，与正式工具箱分开。视频播放器和模块测试宿主仍为本地材料。音乐可执行模块包另放在仓库 modules/packages/external-android-apps/ 中。代码许可与附带素材许可分别以公开目录中的许可文件和来源说明为准；音乐默认曲绘的说明见 `modules/music/ASSETS.md`。公开交付不包含签名私钥、凭据、SDK、AVD、构建缓存、测试聊天内容或用户音频文件。
