## 设备检查

API 35 隔离模拟器：中文 368 项、英语 366 项通过，覆盖既有真实 PCM/AAC、剪辑、倍速、音量、内嵌元数据、歌单和分析回归，以及本次新增功能：

- LRC 四句窗口、前后跳转、长句换行、黑色当前句与字号、即时字号更新、绝对路径/file/content URI、同路径刷新、切歌隔离、失败重试与释放。
- 歌词同名副本不覆盖、同目录直接使用及回滚不删除源文件、实际读取 2 MiB 上限、二进制拒绝、失败保留原绑定。
- 标签多项增删、标点保留、取消不写入、按解码后标签检索。
- 歌曲按钮内部右侧人员区域仍可整行点击，三行批量操作与下方全选顺序。
- 定时默认完成当前曲、1/120 分钟边界、非法值不覆盖、取消和重设、暂停/载入到期、等待期间切歌或暂停、自然曲终不循环及前台服务停止。
