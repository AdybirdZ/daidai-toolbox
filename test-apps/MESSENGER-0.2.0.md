# 呆呆传话 0.2.0

独立测试版，包名保持 `org.daidai.prototype.messaging`，versionCode=2，继续使用原型签名，可覆盖安装 0.1.0。测试 APK 与正式工具箱分开发布，未合并到工具箱。

## 功能

- 新增“局域网 / 蓝牙”通信方式，记住选择；切换方式断开连接并清空当前会话。
- 经典蓝牙 RFCOMM 双向文字传输，复用原有配对码、AES-GCM 加密和会话验证。
- 已配对手机选择，设备名称与地址在选择框中显示；提供系统蓝牙设置入口。配对必须先在系统设置中完成。
- Android 12+ 按需请求“附近的设备”连接权限；不请求扫描、广播或定位权限。拒绝蓝牙权限后仍可使用局域网。
- 处理未支持蓝牙、蓝牙关闭、没有已配对设备、权限拒绝/撤回、连接与验证超时、断开与重连；切后台自动释放监听和 Socket。
- 系统蓝牙配对确认与本程序 16 位配对码均需完成，二者含义不同。
- 配对码、所选蓝牙设备地址与聊天不落盘；复制配对码时设置系统敏感标记（Android 13+）。

## 使用

1. 两台 Android 手机安装传话 0.2.0，在系统设置中开启蓝牙并彼此配对。
2. 返回程序，两台都选择“蓝牙”，按提示允许“附近的设备”权限。
3. 一台点“等待另一台连接”。
4. 另一台点“选择已配对手机”，选择前者，输入前者显示的 16 位配对码，然后“连接对方”。
5. 显示“蓝牙已连接 · 加密会话”后互发消息。无需互联网，也不需要同一 Wi-Fi。

Android 8+；两端需支持经典蓝牙。该功能不适用于普通 iPhone 经典蓝牙聊天。与 BLE 外设、耳机或其他聊天程序不兼容。

## 验证边界

本目录核心测试覆盖共用加密协议、字节流会话和本机 TCP 通信，不模拟手机射频。真实蓝牙链路、通信距离、路由器客户端隔离及厂商系统限制仍需在目标设备验证。协议尚未经过独立安全审计，不应用于高敏感通信。
