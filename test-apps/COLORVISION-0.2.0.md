# 呆呆色觉模拟 0.2.0

独立测试版，可覆盖安装 0.1.0。测试 APK 与正式工具箱分开发布，未合并到工具箱。

- 原图、红色盲、绿色盲、蓝色盲改为多选，默认四项全部显示；可选择 1～4 个视图，自动分屏对照。
- 图片和实时相机都支持分屏，各模式保留完整画面比例。所有相机视图共用同一帧，不重复打开摄像头。
- 修正相机方向：纹理已包含传感器旋转和镜像，移除旧版再次叠加的变换，按显示方向补偿横竖屏。
- 本地图片可导出当前布局的 PNG 对照拼图；选择组合在本机保存。中英文 XML 同步更新。

使用 Machado 2009 近似模型；图片及 PNG 拼图长边不超过 2048 像素。算法来源与许可见 `NOTICE.md`，使用说明解释近似效果与本机处理范围。摄像头离开应用即关闭。

本目录核心测试覆盖色彩变换和分屏几何。真实手机上的画面方向、自动白平衡与性能仍需在目标设备确认，纯 Java 测试不能替代设备测试。
