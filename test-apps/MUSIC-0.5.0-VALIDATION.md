# 呆呆音乐 0.5.0 验证记录

日期：2026-11-10。音乐 0.5.0 / versionCode 5，正式工具箱仍为 2.2.0 / versionCode 50。已完整阅读开发者准则及原型约定，按音乐范围核验。

- 公开快照便携核心测试 2445 项通过；不含本地视频原型。音乐限定源码包解压后，4 套 120 项核心检查通过，独立构建成功。
- 从公开快照及音乐限定源码包分别构建的 APK，与交付 APK 排除签名后的所有 ZIP 载荷逐字节相同。
- 最终 APK 在 API 35 隔离模拟器通过 247 项英语设备检查；中文页面此前已通过同范围检查，并目测了中文/英语播放、设置、我的歌曲、波形与频谱。设备检查数包含缓存交界处轮询断言，会随运行时长略有变化。
- 覆盖指定 SAF 文件夹扫描、内嵌曲绘/BPM/演唱者、复制完整性、同名文件不覆盖、相同显示歌名保持不同文件身份、目录外编辑/删除阻止、确认删除、资料精度及播放列表批量移除。
- 覆盖按下时刻测 BPM、整数/一位小数写入、应用内音量及上限、系统音量不变、回到开头保持暂停、倍速音调、PCM/AAC 剪辑、曲绘原字节保存。
- 覆盖真实左右声道、440 Hz 源频率、三模式切换、8 秒缓存交界、短距离回拖、过期解码隔离、失败退避及临时文件清理。修复旧媒体会话停止请求影响新播放的竞态；回归验证旧控制器无效、当前控制器仍可停止及重新播放。
- 本地与公开模块工具各 33 项容器检查通过；核对 APK 版本、包名、真实签名、大小/哈希、配置契约及异常容器拒绝。正式 3.0.0 宿主尚未发布；本次未将模块装入正式工具箱。
- 三套音乐 XML 各 232 键，键及格式占位符一致，默认与中文内容一致。模块无启动壳生成 R 或工具箱私有类依赖，无新增第三方运行时库，无网络、录音或广泛存储权限。

APK 签名保持原型证书，SHA-256：`0d4d9d87dfb81fa0ea922fc764ff4326d16284ca69ca8715bca247e22973e1f4`。交付哈希见 `SHA256SUMS.txt`。测试仅使用生成音频及合成标签，不接触用户媒体。

未全面验证实体手机、全部厂商解码器、云盘、蓝牙音频路由、Android 8–9 曲绘保存及正式未来宿主。Android 8–9 使用系统选择器保存曲绘，Android 10 起使用 Pictures/呆呆音乐相册。慢速或损坏音源仍可能暂时无分析数据。
