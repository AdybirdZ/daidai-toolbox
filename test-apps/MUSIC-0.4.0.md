# 呆呆音乐 0.4.0

独立测试版，Android 8.0 及以上，包名 `org.daidai.prototype.music`。测试 APK 与正式工具箱分开发布，未合并到呆呆工具箱。可使用原型签名覆盖安装旧版，保留歌曲资料。

## 曲库、歌单与搜索

- 歌曲资料包含名称、作曲、编曲、演唱者、备注、风格标签、BPM、评分、纯音乐标记、LRC 歌词和封面。BPM 与评分未填写时留空，评分可明确设为 0 分。
- 默认封面采用用户提供的蓝色音符图片。带有内嵌封面的歌曲优先使用自己的封面，无需另行导入图片。
- 从电脑复制到已授权指定文件夹的音频，打开“我的歌曲”或重新扫描时会直接读取文件内嵌的封面、每分钟节拍数（BPM）、艺术家、作曲和编曲信息，并将常见 ARTIST／TPE1／©ART（参与创作的艺术家）填入“演唱者”；仅有专辑艺术家时才作为回退，无需再次手动导入封面。支持常见 MP3、FLAC、OGG/Opus、M4A、WAV 和 WMA 标签，具体字段仍取决于文件是否确实写入及系统文件提供方是否允许读取。
- 电脑音乐软件只保存在自身数据库中的资料不会随音频文件复制。要自动带到手机，资料必须写入音频的标准或受支持自定义标签；否则可在手机的歌曲资料中补充。
- “我的歌曲”显示已导入歌曲及已授权存储文件夹中可读取的音频，可编辑资料、勾选加入播放列表或一键全部加入。指定文件夹通过系统选择器授权，不扫描未授权目录。
- 歌单支持新建、重命名、确认删除、添加歌曲和移除歌曲；内置“我喜欢的音乐”歌单，播放页可用爱心收藏或取消收藏。
- 曲库与当前播放列表分开保存。清空或移除播放列表项保留歌曲资料、歌单、收藏、歌词、封面及音频文件。
- 搜索单独成页，搜索范围覆盖歌曲资料与时长。可按歌名、作曲、编曲、演唱者、评分和 BPM 分类。分类初始折叠，更换分类后重新折叠；清除搜索条件同时清空输入和筛选。
- 姓名与歌名按中文、英文、其他文字分组；中文采用系统拼音转换，同组按拼音或名称排序。多音字转换及混合文字的语言归类可能需要人工核对。多位创作者可用顿号、逗号、分号、斜线或 `&` 分隔。
- 搜索命中的分类显示深色底、白色文字，并保持原有顺序移到前面。BPM 分类为小于 100、100～130、大于 130 且不超过 160、大于 160；边界不重复。

## 播放、剪辑与示波器

- 播放倍速为 0.5～2 倍，默认保持音调；可启用“音调随倍速改变”。“结束播放并归零”释放播放器，下一次从歌曲开头播放，与暂停区分。
- 剪辑的起止时间基于原始音频。选择保留或去除片段后点击“应用本次剪辑”，可重复操作、撤销或重置。导出时按原顺序拼接剩余片段，原文件不变。
- 默认倍速仅影响试听，导出为原速 PCM WAV；可选择导出时应用当前倍速与音调设置。保持音调的离线处理使用本地波形重叠方法，可能产生音质变化，不属于专业母带处理。
- 普通示波器显示左右声道波形；X-Y 模式以左声道为横轴、右声道为纵轴，单声道显示对角线。图形跟随当前播放位置，源自歌曲文件，不含倍速、音调或系统音效处理，静音时也能查看。无需录音权限。
- 剪辑与示波器使用私有临时 PCM 文件，取消、失败、完成导出或关闭示波器时清理。单次剪辑临时 WAV 上限为 512 MiB，另预留 16 MiB 空间；导出加速效果可能同时需要两个临时文件。支持格式由设备解码器决定，不保证所有编码格式可用。

## 构建与验证

在本目录执行：

```powershell
python build.py music --sdk C:\Android\Sdk --out-dir C:\Temp\daidai-test-apps
python test.py
```

测试安装包位于仓库 `test-apk/`。构建脚本只使用本机 JDK 和 Android SDK，不自动下载依赖。默认签名只用于个人开发；覆盖既有安装包须使用相同签名。

旧版零评分与“未填写”无法区分，升级将旧的 0 视为未填写；本版新设置的 0 分独立保存。原有参与创作的艺术家资料作为演唱者迁移，可在编辑界面修订。BPM 小数按四舍五入保存为整数；不读取通用 CUE 或旁车文件。已授权文件夹不会实时监听文件变化，需重新打开或扫描“我的歌曲”。未在真实手机上覆盖所有厂商解码器、音频焦点、后台限制和存储提供方，模拟器结果不能替代全部真机验证。

音乐清单保留 `daidai-android-app/1` 适配标识。当前正式工具箱尚无 3.0.0 模块安装器，本目录不包含测试宿主或模块容器。
