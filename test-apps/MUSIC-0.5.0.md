# 呆呆音乐 0.5.0

Android 8.0 及以上的独立本地音乐测试应用，包名 `org.daidai.prototype.music`。与正式工具箱分开安装，已准备简体中文和英语资源。0.5.0 的底部栏目为“播放”“我的歌曲”“设置”。

## 播放与资料

- 导入前选择歌曲存储文件夹；音频复制到该目录后播放，已在目录中的文件直接使用。复制会占用存储空间，同名文件另加序号，不覆盖现有文件。
- “我的歌曲”提供目录扫描、分类搜索、歌单、喜欢、资料编辑和确认后删除音频文件。播放列表仅控制播放顺序，批量移除不会删除文件。
- 曲库以文件 URI 区分歌曲，歌曲显示名称可以相同。修改名称不会改动文件名，也不会覆盖同名歌曲；手工资料保存在应用私有目录，不写回文件内嵌标签。
- 可读取文件内嵌曲绘、BPM、作曲、编曲及演唱者。电脑软件私有数据库中的信息不能随音频文件自动转移。手动 BPM 保留十进制精度；节拍测量按按下时刻计数，结果可按整数或一位小数写入测量时选中的歌曲。
- 应用内音量为 0～设定上限，上限默认 100%。首次使用音量为 0%，仅改变应用播放器，不改系统媒体音量。“回到开头并暂停”保留当前歌曲。
- 支持后台/锁屏媒体控制、0.5～2 倍播放、可选保持音调，以及多次保留/去除片段后拼接导出 WAV。导出默认不应用试听倍速；不会覆盖原音频。
- 点击曲绘进入黑底预览，可双指缩放。Android 10 及以上保存至 `Pictures/呆呆音乐`；Android 8–9 通过系统选择器指定保存位置，避免申请广泛存储权限。

## 音频分析

音频分析嵌入曲绘与歌曲名称之间，可切换时域波形、X-Y 示波图和频谱。

- 时域波形展示左右声道随时间变化的归一化振幅，滑块调整纵向范围，四周显示刻度；X-Y 示波图以左、右声道分别作为横、纵轴。
- 频谱使用 Hann 窗和 FFT，纵轴为 dBFS，横轴默认对数频率，可切换线性频率，支持双指横向缩放。可标注 0～10 个主要频谱峰值，默认 3 个；下方频谱历史展示随播放推进的变化。
- 提前解码下一段 8 秒 PCM，窗口留有重叠以覆盖交界处的分析采样。切换歌曲、跳转及关闭时取消过期任务并释放缓冲。慢速云盘、损坏文件或设备解码限制仍可能导致数据暂不可用。
- 图形来自原音频文件，不采集麦克风，不测量环境声压级，也不包含播放倍速、音调或设备音效处理。

## 模块与后续整合

可复用代码在 `modules/music/`，独立入口在 `launchers/music/`。播放服务、曲库/存储、分析和界面分别维护；分析核心不依赖 Android，嵌入面板通过 `PlaybackCursor` 接口读取宿主状态。完整边界见 `docs/MUSIC-ARCHITECTURE.md`。

另提供包含实际音乐 APK 的 `.ddapp` 包，使用 `daidai-android-app/1` 契约。当前正式工具箱尚无 3.0.0 安装器；该包供未来宿主安装、启动及卸载独立 Android 音乐应用，不能视为已经在工具箱内实装。跨包名整合不能直接继承 SAF 文件授权，仍需用户重新选取。

## 构建与验证

在原型目录运行 `python build.py music`、`python test.py`。公开快照支持 `--sdk` 与 `--out-dir`，详见该目录 README。模拟器测试包含合成音频、指定文件夹授权、元数据、播放、交互和分析；厂商设备、全部解码格式及云端文件提供方未全面实测。默认曲绘许可单独见 `modules/music/ASSETS.md`。
