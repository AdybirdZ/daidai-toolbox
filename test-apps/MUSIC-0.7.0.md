# 呆呆音乐 0.7.0

Android 8.0 及以上的独立本地音乐测试应用，包名 `org.daidai.prototype.music`。底部栏目为“播放”“我的歌曲”“设置”，提供简体中文与英语。音乐作为一个完整应用模块维护；播放、曲库和音频分析是其内部组件，不需要分别安装。

## 本版变化

- 歌词显示上一句、当前句和后两句；当前句使用黑色大字，其余使用稍小的深灰字。可在设置中调整当前句字号，范围 14～36 sp，默认 22 sp。
- 导入 LRC 时复制到所选歌曲存储文件夹；已在该文件夹内的歌词直接使用，同名文件添加序号，不覆盖原文件。旧版已绑定的本地歌词仍可读取。
- 播放页增加定时停止播放，可设 1～120 分钟，默认到时播放完当前歌曲后停止。计时按经过时长推进；暂停不冻结计时，计时状态不跨进程重启恢复。
- 作曲、编曲和演唱者保持在整行歌曲按钮内部靠右，长内容换行显示，不越出按钮。
- 风格标签支持逐项添加与移除，保留每个标签自身的标点，并兼容旧版分隔文本。
- “我的歌曲”的加入歌单、加入播放列表、删除所选歌曲各占一行，全选框位于三项操作下方。

## 存储、资料与播放

导入前须通过系统选择器授权歌曲存储文件夹。音频复制到该目录后播放，已在目录中的文件直接使用；复制占用存储空间，同名文件添加序号而不覆盖原文件。曲库以文件访问地址识别歌曲，显示歌名可以相同；编辑显示名称不会重命名或覆盖音频。手工资料保存在应用私有存储，不写回文件内嵌标签。

扫描或导入读取文件实际内嵌的曲绘、BPM、作曲、编曲及艺术家信息，艺术家映射至演唱者。仅存在电脑播放器私有数据库的资料不能随音频文件自动转移。支持 LRC 歌词、备注、多项风格标签、0～10 分评分以及纯音乐标记；未填写 BPM 和评分时保持为空。节拍测量按按下时刻计数，可按四舍五入整数或一位小数写入选中的歌曲。

LRC 歌词保存在指定文件夹中，其与歌曲的绑定仍由应用管理；更换文件夹不会自动搬移之前导入的歌词。复制失败保留原有绑定，撤销文件夹授权后需重新授权才能读取。纯音乐歌曲显示“纯音乐”；无有效时间戳的歌词不能按播放位置同步。

从播放列表或歌单移除只删除引用；“删除歌曲”会在确认后删除存储文件夹中的真实音频及对应应用记录，无法撤销。文件提供方拒绝删除时保留未删除的记录并报告结果。卸载应用会清除私有资料及授权，所选文件夹中的音频按文件提供方规则保存。

播放支持上一首、下一首、播放/暂停、播放方式、回到开头并暂停、喜欢、倍速、剪辑与音频分析。应用内音量首次为 0%，最大值默认 100%，只影响本播放器，不改变系统媒体音量。定时停止播放默认等正在播放的歌曲自然结束，随后不再循环或播放下一首；等待期间手动暂停或切歌会立即停止。若到时已暂停或仍在载入，则直接停止。普通暂停期间仍保留媒体服务用于控制，系统强制停止会结束计时。支持后台及锁屏媒体控制，耳机断开暂停；0.5～2 倍播放默认保持音调，也可随倍速改变音调。多次保留/去除片段可拼接导出 WAV，默认不应用试听倍速，不覆盖原文件。

点击曲绘进入黑底预览，可双指缩放。Android 10 及以上保存到 `Pictures/呆呆音乐`，Android 8～9 使用系统选择器保存，不申请广泛存储权限。默认曲绘的许可范围见 `modules/music/ASSETS.md`。

## 音频分析与限制

分析面板位于曲绘下方、歌名上方，切换时域波形、X-Y 显示或频谱，不另占播放操作界面。时域波形显示左右声道归一化振幅，可调纵向范围并查看刻度；X-Y 显示分别以左、右声道为横、纵轴。

频谱使用 Hann 窗和 FFT，纵轴为 dBFS，横轴默认对数频率，可切换线性频率。频谱历史的顶部表示当前音频位置，底部表示所选历史时长。图表基于原文件解码样本，不包含播放器倍速、音调、音量及设备音效处理，不采集麦克风，也不测量环境声压级。分析任务提前解码下一段 8 秒 PCM；慢速文件提供方、损坏文件及解码器限制仍可能造成短暂缺失，不用补画数据冒充真实采样。

## 模块、构建与验证

可复用实现位于 `modules/music/`，独立入口在 `launchers/music/`，公共小型界面工具在 `shared/`。所有音乐功能和资源随同一个音乐 APK 交付，内部类的拆分仅用于维护和测试。架构和未来迁移契约见 `docs/MUSIC-ARCHITECTURE.md`。

另提供内含实际 APK 的 `music-0.7.0.ddapp` 容器，采用 `daidai-android-app/1` 契约。未来宿主可验证后交由 Android 安装独立音乐应用；当前正式工具箱尚无 3.0.0 安装器，也不支持同进程动态嵌入。包内不含用户歌曲与私有资料，跨包名不能自动继承文件夹授权；完整音乐资料转移桥接尚未实现。

原型目录运行 `python build.py music` 与 `python test.py`；公开快照可指定 SDK 和输出目录。交互、文件授权、解码与后台播放须另外执行设备测试，实际通过结果由本版验证记录填写。厂商设备、全部编解码器及云端文件提供方未全面验证，不以构建成功代替验收。
