# 技术边界

## 通信协议 DDM/1

- 两种传输：局域网 TCP 42424 与经典蓝牙 RFCOMM；应用层 DDM/1 协议共用，一对一，无自动发现，无云中继。
- 蓝牙使用安全 RFCOMM Socket 和独立服务 UUID `5f917b67-4f75-4af0-b2ca-a73c471a20ee`；两端先在系统设置中配对，连接方通过此 UUID 的 SDP 服务记录连接。不使用 BLE、反射私有 API 或硬编码 RFCOMM 通道号。接收方不必在程序中选择对端，连接方选择已配对手机。
- 蓝牙连接超时 25 秒，应用层验证超时 15 秒；超时和取消时关闭底层 BluetoothSocket 以解除阻塞。监听可持续到用户取消或切后台。配对码错误后蓝牙会话关闭，接收方需重新点击等待连接；局域网的错误配对码处理保持继续等待。
- `MessagePeer` 统一宿主入口；`StreamSession` 处理蓝牙字节流上的加密与收发，`BluetoothPeer` 只管理 Android RFCOMM 生命周期。Android 系统蓝牙配对提供链路安全，应用层仍验证独立的 16 位配对码。
- 配对码：SecureRandom 生成 16 个字符，32 字符表，约 80 位随机熵；排除 I、O、0、1 以减少误读。不是用户自定义的短密码。
- 双方发送协议标识与各自 32 字节随机数；按服务端/客户端顺序拼接并 SHA-256 得到会话盐。
- PBKDF2-HMAC-SHA256（100000 轮、256 位）从配对码和会话盐派生密钥。
- AES-256-GCM；每包随机 12 字节 nonce、128 位 tag；附加认证数据包含会话摘要、方向和单调递增序号。握手双方都必须通过加密确认消息。
- 每条最多 4096 UTF-8 字节，入站帧长度先检查再分配内存，非法 UTF-8 拒绝。头部中的版本、随机数与包长可见，正文加密。
- 每次连接重新生成随机会话；错误配对码不能建立会话。每方向序号校验拒绝同一会话中的重放，方向标记防止反射。
- 初始连接/认证有超时；错误配对者断开后，接收端继续等待。已经认证后的静默会话无需持续发送心跳。
- 尚未实现自动发现、多端聊天、离线投递、文件传输、历史记录、后台收信、已读回执。UI 的“我”表示本端写入 Socket 成功，不代表对端已读。蓝牙只支持具备经典蓝牙的 Android 手机，不保证与 iPhone 的普通蓝牙互通。
- 该协议为原型，未独立审计，不承诺抵御所有网络攻击。公开测试不代表完成独立协议审查；不要把配对码公开或重复用于其他系统。

## 播放

- SAF 授权 URI + Android MediaPlayer；依赖设备支持的编解码器，不在 APK 内捆绑编解码库。
- 服务、媒体会话、通知互相同步。缓冲/准备在播放器异步回调中完成，主线程不解码文件。
- 音频焦点暂失时暂停，焦点恢复时只恢复此前正在播放的音频；永久失去焦点不自动恢复。耳机断开暂停。
- 不保存播放进度；列表、播放模式、应用内音量、音量上限和倍速保留，应用重新启动后需要手动选择/播放，不自动开始后台播放。
- 最多 500 条列表项。文件移动、权限失效、格式不支持时显示错误并停止，不循环重试坏文件。
- 首次应用内音量为 0%，最大值默认 100%，只作用于 MediaPlayer。所有换歌、启动、焦点恢复和倍速路径统一应用播放器音量，临时降低音量不能超过配置上限。调整倍速时先置零音量，处理 MediaPlayer 可能自动启动的行为，再恢复原播放/暂停状态及音量策略。倍速范围 0.5～2，默认保持音调，可改为音调随倍速变化；解码器不支持时提示。
- 剪辑可连续保留或去除多个片段，按原顺序拼接，不是多轨编辑器；起止时间以原音频的秒数输入，可使用当前位置标记、试听。预览终点以主线程约 40 ms 间隔检查，受调度及音频输出缓冲影响，不等同于导出精度。导出使用解码输出采样帧边界；时间戳先映射回采样帧，避免微秒量化引入重复一帧。PCM16、8/24/32 位和浮点解码结果统一输出 PCM16 WAV，保持原采样率和声道，默认不应用试听倍速；可选择在导出时应用当前倍速和音调设置。超过 RIFF 大小范围时停止并提示，不截断生成损坏文件。
- 导出先写应用缓存、完成后复制到系统选择器指定的文件；需要临时文件与目标文件的存储空间。WAV 不压缩，立体声 48 kHz / 16 位约 11.5 MB/分钟。格式支持依设备，受保护文件可能不可解码；本版验证了 PCM WAV 和 AAC，其他系统支持格式需实机确认。

## 色觉模拟

- CPU 图片与 GPU 相机使用同一组 Machado 2009 严重程度 1 矩阵。先将 sRGB 转为线性光，计算矩阵、裁剪至显示色域，再编码为 sRGB；不是直接对非线性 RGB 乘矩阵。图片保留透明度；原图模式不变换图片像素。
- Camera2 → SurfaceTexture → OpenGL ES 2.0 外部纹理，随实际相机帧到达渲染，不逐帧读回到 CPU。一个相机输出共用给原图和三种模拟，在同一帧绘制到 1～4 个视口；不同时打开多个摄像头。图片和相机共享分屏几何，标签位于画面外。
- 预览采用 SurfaceTexture 自带的传感器旋转与镜像变换，只补偿显示屏旋转；宽高比根据纹理是否交换轴及显示方向计算。0.1.0 重复叠加传感器方向，0.2.0 已移除。预览与 Android 原生 TextureView 对照时，须对 `getBitmap()` 返回的纹理内容另行施加 View 的显示变换，否则横屏对照数据错误。选择不超过 1280×960 的可用预览尺寸，保留完整画面宽高比。实际帧率受相机、GPU、温度等影响，不承诺固定帧率。
- 摄像头权限拒绝时保留图片功能。切后台、系统选择器或退出页面时关闭相机、会话及预览 Surface；返回后重新打开。代次标记拒绝过期的异步回调，避免旧相机重新占用资源。
- 图片在工作线程按采样缩至长边不超过 2048 像素，处理 EXIF 方向，并缓存三种模拟；切换视图组合不重复解码。默认原图、红、绿、蓝全部显示，至少保留一项；选择在本机保存。PNG 导出包括当前所选视图、标题和布局，长边不超过 2048 像素。色域/显示器和相机自动白平衡等会影响实际效果，不声称是任何特定人的真实视觉。
