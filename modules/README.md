# 应用模块

11 个完整应用均使用签名 `.ddapp` 在工具箱内运行，当前接口为 `daidai-toolbox/api-2`。宿主 3.0.10 / 67 与 11 个应用包一同升级；api-1 应用包不能在新宿主中运行，必须更新。历史发布资料独立保留，实际交付以发布记录为准。

| 目录/文件 | 用途 |
| --- | --- |
| `apps/` | 天气等原八个应用的业务、界面和设置源码 |
| `embedded/` | 音乐、设备通信和色觉模拟器的完整代码与资源 |
| `prototypes/ball-race/` | 本地小球竞赛测试宿主和原型，不参与正式宿主构建 |
| `store/<版本>/` | 各版本商店目录及签名可执行包 |
| `icons/` | 应用图标原图、原创 SVG 及素材说明 |
| `stable-resource-ids.txt` | 稳定资源编号，只能增补 |
| `resource_partition.py` | 按宿主/应用实际引用划分原八应用资源 |
| `build_executable.py` | 构建执行包、描述清单、商店目录与默认应用 |
| `packages/` | 历史配置契约及旧独立 APK 容器，不能用于当前内部安装 |

默认安装天气和状态，设置与商店固定。桌面可自定义排序、文件夹与尺寸；应用内底栏只提供桌面入口。卸载默认保留资料，全部应用均可独立导入导出和管理保留数据。

一个应用仅一个安装项；音乐内部组件不另做模块。正式 3.0.0 取消从旧独立音乐导入资料的专用迁移流程，保留内部音乐的统一备份与恢复。原八应用的大部分专用业务和资源已分包，小型共享 DTO、校验契约和 Android 组件桥仍在宿主。视频播放器仍仅本地，计算器不恢复。旧内测目录仅供其对应接口宿主使用，不将旧包视为 api-1 兼容包。

详见 [宿主说明](../docs/MODULE-HOST.md)、[后续计划](../docs/ROADMAP.md) 和 [验证记录](../TESTING.md)。

应用包版本不得高于已安装宿主版本。3.0.5 应用包要求宿主版本代码至少 61，旧的 3.0.0 至 3.0.4 应用包在接口及最低版本条件满足时仍可运行。商店入口为 `store/catalog.json`，安装包按 `store/<版本>/` 独立留存。
