# 应用模块

当前内测宿主为 pre-3.0.0-3，11 个完整应用均在工具箱内运行。

| 目录 | 用途 |
| --- | --- |
| `apps/` | 天气等原 8 个应用的独立 DEX 入口 |
| `embedded/` | 音乐、设备通信、色觉模拟器的完整代码、资源和署名 |
| `store/pre-3.0.0-3/` | 当前商店目录及 11 个签名可执行 `.ddapp` |
| `icons/` | 应用图标原图、其余原创 SVG 及素材说明 |
| `store/pre-3.0.0-1/`、`store/pre-3.0.0-2/` | 历史内测版目录，仅对应宿主使用 |
| `packages/` | 历史配置契约及旧独立 APK 容器，不适用于当前内部安装 |

默认安装天气和状态，设置与商店固定。卸载保留个人资料；执行包绑定精确宿主 ABI。一个应用仅一个安装项，音乐内部组件不另做模块。视频播放器仍仅本地，计算器不恢复。

详见 [宿主说明](../docs/MODULE-HOST.md)、[音乐迁移](../docs/MUSIC-MIGRATION.md) 和 [验证记录](../TESTING.md)。
