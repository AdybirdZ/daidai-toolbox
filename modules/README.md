# 未来宿主的模块边界

本目录包含两种不同的交付，正式 3.0.0 宿主尚未发布，当前工具箱 2.2.0 没有模块下载或安装功能。

| 类型 | 位置 | 内容与当前能力 |
| --- | --- | --- |
| 既有栏目的配置与身份资产包 | [`packages/3.0.0/`](packages/3.0.0/) | 清单、配置契约、权限说明及版本要求，不含独立可执行代码，`standaloneInstallable` 为 `false` |
| 外置 Android 应用模块 | [`packages/external-android-apps/music/0.5.0/`](packages/external-android-apps/music/0.5.0/) | 呆呆音乐 0.5.0 的 `.ddapp` 容器，包含真实音乐 APK，`standaloneInstallable` 为 `true`；APK 能由 Android 单独安装，接入工具箱仍需要未来宿主 |

既有栏目沿用 `modules.json` 中的稳定 ID，包含天气、天气地图、状态、课程表、天文、地震、随机抽取和待办事项，全局设置另有宿主基础包。默认衔接模块为天气、状态和待办事项。这些资产包用于明确边界与配置迁移，不应当被称为已经拆分完成、能够独立运行的应用。

配置导出文件采用现有校验格式并增加 `module` 字段；导入时确认后只覆盖所选模块。权限、缓存、接口限流、最近定位及正在运行的任务不会随配置恢复。

音乐的外置应用契约为 `daidai-android-app/1`，采用独立 Android 包、进程、私有数据和文件授权。未来宿主可校验并请求系统安装、显示入口、打开或卸载音乐，不能静默安装或直接读取私有曲库。安装音乐模块不等于将音乐界面嵌入工具箱，也不会把另一应用的文件夹 URI 授权自动转移。完整音乐资料导入导出桥接尚未实现，具体边界见[音乐架构说明](../test-apps/docs/MUSIC-ARCHITECTURE.md)和[容器契约](../test-apps/module-packages/README.md)。

音乐、传话和色觉模拟的独立测试 APK 放在 [`test-apk/`](../test-apk/)，与正式工具箱分开。音乐可执行模块另列版本目录与校验信息，未将完整工具箱复制成多个模块。视频播放器仍仅本地保存；计算器已取消，不保留模块计划。
