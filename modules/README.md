# 应用模块

`pre-3.0.0-1` 已实现图标桌面、GitHub 应用商店与可执行应用安装。

| 目录 | 当前用途 |
| --- | --- |
| `apps/` | 8 个工具箱内应用的 Java 入口与内部类，参与独立 DEX 构建 |
| `store/pre-3.0.0-1/` | 商店目录及与本版宿主 ABI 对应的签名 `.ddapp` 执行包 |
| `icons/` | 全部应用、商店及设置的原创 SVG 图标源；Android 对应资源在 `app/src/main/res/drawable/app_*.xml` |
| `packages/3.0.0/` | 历史 2.1.5 清单与配置契约资产，不含执行代码，不能安装为应用 |
| `packages/external-android-apps/` | 音乐历史及当前独立应用容器；0.7.0 可由本版宿主导入并交 Android 安装 |

默认安装天气、状态；两者均可卸载。设置、应用商店、全局管理及完整配置转移为宿主能力。天气地图、天文、地震、课程表、随机抽取和待办事项按需安装。音乐、传话、色觉模拟由系统独立安装，可从工具箱桌面打开；视频播放器仍仅本地，计算器已取消。

执行包采用与宿主相同的原签名，并声明精确宿主 ABI，不接受任意第三方可执行文件。历史 metadata-only 包保持原有标识，不会被冒充为可运行应用。一个应用是一个安装项，音乐内部功能不会拆成多个安装包。

详见[宿主说明](../docs/MODULE-HOST.md)、[开发者准则](../docs/DEVELOPER-RULES.md)。
