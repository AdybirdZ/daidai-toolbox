# 3.0.0 模块边界

本目录记录正式工具箱的稳定模块身份，并提供面向 3.0.0 宿主的模块资产包。每个模块使用 `modules.json` 中的稳定 `id`，资产包位于 `packages/3.0.0/`。

当前资产包是宿主扩展包，包含模块清单、配置契约、权限说明和版本要求；它们要求未来的 3.0.0 宿主，不能在 2.1.5 中独立安装，也不是把完整 APK 复制成多个假模块。真正的下载、安装、卸载和运行时加载由 3.0.0 宿主实现。

配置导出文件采用现有配置校验格式并增加 `module` 字段；导入前会校验格式、类型和模型数据，确认后只覆盖所选模块。权限、缓存、接口限流、最近定位和正在运行的任务不会随配置文件恢复。

已实装栏目均有资产包：天气、天气地图、状态、课程表、天文、地震、随机抽取和待办事项；全局设置另有宿主基础包。默认衔接模块为天气、状态和待办事项。音乐播放器等独立原型不属于本目录，也不会随正式模块包上传。
