# 3.0.0 模块边界

本目录记录正式工具箱的稳定模块身份，供后续 GitHub 模块下载器使用。2.1.5 只提供模块化数据交换，不从网络下载、安装或卸载模块。

每个模块使用 `modules.json` 中的稳定 `id`。配置导出文件采用现有配置校验格式并增加 `module` 字段；导入前会校验格式、类型和模型数据，确认后只覆盖所选模块。权限、缓存、接口限流、最近定位和正在运行的任务不会随配置文件恢复。

默认衔接模块为天气、状态和待办事项；所有现有栏目都保留独立 ID，课程表、天文、地震、随机抽取和全局设置可以单独导入导出。GitHub 下载与 Android 动态安装属于后续版本范围。
