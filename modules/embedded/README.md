# 内部应用源码

| 目录 | 应用 |
| --- | --- |
| `music/` | 音乐 |
| `messaging/` | 设备通信 |
| `colorvision/` | 色觉模拟器 |
| `shared/` | 内部应用共用的界面辅助代码与资源 |

每个应用是一个完整安装项，有自己的资源表、业务实现与资料目录，以签名 `.ddapp` 在宿主内运行。音乐的播放、曲库、歌词、剪辑、示波器和频谱只做内部代码分层，无需分别安装。源码中的稳定包路径与历史通信标识不随显示名称修改。

宿主提供 `ModulePage`、`ModuleWorker`、Android 前台服务桥、应用私有目录和资料转移契约；应用页面与后台工作共用一个类加载器。接口为 `daidai-toolbox/api-1`，不使用精确显示版本作为接口名。内部应用共用宿主 UID 和权限，不能按独立 Android APK 的权限隔离理解。

后续只更新内部应用包；旧独立 APK 及一次性音乐迁移辅助包保留为历史资料。正式 3.0.0 不再提供旧独立音乐的专用同机迁移入口或导入导出，内部应用与旧独立版的私有数据不直接互通。当前内部音乐仍支持宿主统一完整备份及单应用资料导入导出。视频播放器仍仅本地，计算器已取消。

数据导入导出、卸载保留、外部音频不随内部资料删除等规则见 [宿主说明](../../docs/MODULE-HOST.md)。测试与发布是否完成以 [验证记录](../../TESTING.md) 及发布记录为准。
