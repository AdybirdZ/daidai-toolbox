# 小球淘汰赛原型

本目录是小球淘汰赛未来内部应用的源码与测试长期存放位置。当前目录不属于常规宿主构建输入，不会自动进入桌面、商店或正式 `.ddapp`。

设计、开发和跨对话交接要求见 [`docs/BALL-ELIMINATION-DDAPP.md`](../../../docs/BALL-ELIMINATION-DDAPP.md)。本目录源码应提交到 Git，并在交接时提供提交 SHA。未来正式接入时，从这里取源码并使用目标宿主重新登记、构建、签名和验证，不直接复用过期安装包。

迁移前先核对 `modules/embedded/ballrace/` 中已有的 `RaceCourse.java` 草稿，保留内容并验证迁移结果。该目录会参与宿主源码编译，不能作为未登记应用的长期原型目录。
