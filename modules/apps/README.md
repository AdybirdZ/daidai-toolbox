# 工具箱应用源码

原八个应用的独立代码位于各自 `java/org/daidai/toolbox/` 目录：天气、课程表、状态、天气地图、天文、地震、随机抽取和待办事项。构建为每个目录生成独立 DEX，并将这些实现类从宿主 DEX 排除。

分包范围包括应用界面、专用设置和业务实现；天气城市目录、天文计算、地震来源处理、设备读取以及课程/待办通知业务由相应应用提供。原资源在 `app/src/main/res/` 集中维护，构建时按实际引用分配到宿主或应用包，城市目录只随天气包分发。固定资源 ID 由上一级 `stable-resource-ids.txt` 维护，新增资源不得重排旧编号。

宿主保留共享资料 DTO/模型、导入校验契约、全局设置及 Android 服务/广播桥。应用缺失时通过明确的能力检查降级，不假定可直接调用未安装应用实现；天文可缺省气象条件，地震可独立请求有时限的定位。所有应用共用宿主进程与 Android 权限，不是权限隔离的第三方插件沙箱。

接口为 `daidai-toolbox/api-2`。安装兼容性依据接口、最低宿主及 Android 版本，不能以显示版本字符串相等代替。3.0.10 的 Java 命名空间变更不兼容旧 api-1 执行包；升级宿主后应从商店更新应用。完整边界、构建与验证入口见 [宿主说明](../../docs/MODULE-HOST.md)。
